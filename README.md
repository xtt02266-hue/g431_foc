# G431 有感 FOC

当前工程固定使用 MT6826S SPI 编码器进行有感控制。

## 目录

```text
Core/                       CubeMX 生成的程序入口和外设配置
Drivers/                    STM32 HAL / CMSIS
firmware/
  app/                      系统调度、生命周期、主机命令、周期策略、标定会话
    private/                应用内部共享状态和辅助接口
  control/                  电流环、速度环、位置环、轨迹、SVPWM
  compensation/             齿槽、摩擦模型与摩擦 Flash 存储
  communication/            PC 协议解析、序列化、UART DMA
  calibration/              参数辨识、采集、编码器自校准
  drivers/                  MT6826S、编码器接口、ADC 输入、OLED
  platform/                 板级初始化和电流偏置校准
  algorithm/                PID
  config/                   电机参数和控制常量
  music/                    音乐调制和曲目
  diagnostics/              观测与调试输出
host/tools/                 PC 历史数据分析脚本
docs/                       使用说明、协议、架构说明
refactor_validation/        离线回归和验证记录
```

代码导航和共享状态边界见 [架构说明](docs/architecture.md)。PC GUI HapticKnobStudio 位于独立工程，
本仓库中的 `communication` 是下位机通信代码，`host` 是 PC 端工具。

通用开发规范见 [嵌入式 C 工程开发规范](AGENTS.md)，主干调用注释规则见其中的 3.7.1 节。

## 构建

配置 Arm GNU Toolchain、CMake 和 Ninja 后：

```powershell
cmake --preset Debug
cmake --build --preset Debug
```

`sensored-debug` 也是有感构建入口。当前目录已删除无感构建开关和兼容分支。
本次重构的检查结果见 [验证记录](refactor_validation/architecture_20261011/RESULTS.md)。

## 固件内置齿槽补偿表

当前固件包含 `firmware/compensation/motor_cogging_builtin.h` 中的 512 点表，修订号 10，
量化 CRC32 为 `0x8706A889`。下载固件后，上电自动加载，不需要在上位机导入 CSV。
表来自 2026-10-12 的 507 个有效双向点；索引 0～4 是旧表辅助估算，仍须实机验证。

内置默认配置采用用户于 2026-10-22 反馈已测试的参数：启用、增益 0.90、
电流限幅 0.080 A、100～200 rpm 淡出，相位偏移为 0。
齿槽与摩擦补偿已接入 POSITION、TORQUE、SPEED、FREE、DAMPING、SPRING、DETENT、LIMIT
全部正常闭环模式；两者仍分别受原使能配置控制，摩擦补偿的出厂默认值仍为禁用。
齿槽保持 500 ms 渐入及 100～200 rpm 淡出；FREE 保留原小阻尼，其它触觉模式使用纯摩擦补偿。
力矩模式的最终 Iq 包含补偿量，但命令和目标力矩遥测仍表示基础给定，不代表轴端实测力矩。
补偿合计仍受各模式原限流约束；电位器力矩模式总电流不超过 ±0.2 A，主机力矩模式还约束总输出斜率。
标定由原会话控制补偿，点位采样不叠加齿槽；辨识、音乐、开环强拖、停机和故障不叠加普通模式补偿。

Flash 参数页地址、版本和记录大小不变。齿槽记录原保留字现在保存内置表 CRC 来源标签：
旧标签记录不会覆盖新内置表，也不会在上电时被擦除；本版本明确保存且标签匹配的配置仍优先，
包括编码器自校准前保存的禁用状态。上位机的保存标记也包含固件内置默认值的断电恢复能力。

本次可下载入口为 `build/Debug/g431_foc.elf` 和同目录 `g431_foc_builtin_cogging.hex`。
使用现有 VS Code 的 `DAPLink: Flash Debug` 任务即可按扇区下载；不要为更新此表而整片擦除电机参数。
本次验证使用 Arm GNU/CMake，Keil 构建与实际下载另行确认；原有 Keil 工程的程序区配置未调整。

## 弹簧、档位与软限位手感

- 弹簧：启动中心附近 0.15° 静区，偏转越大逐渐增硬，并按刚度增加回中阻尼。
- 档位：每档独立吸附中心，跨过 55% 档距才换档，往返有 10% 档距迟滞；档心有静区。
- 软限位：范围内没有虚拟墙力；越界后渐硬，仅阻尼继续越界的运动，返回时不施加向外阻力。

默认基础刚度分别为 Spring 0.12、Detent 0.40、Limit 0.80 A/rad；基础阻尼仍为
0.002 A/(rad/s)，24 档/圈，限位半范围 90°。参数的单位、字段顺序与上下位机协议未变。
三个模式的合成电流斜率由 1 提高到 20 A/s，保持原最大电流；FREE/DAMPING 保留 1 A/s。
这属于触觉行为调整，新增参数和曲线尚须实机确认，不把离线结果当作手感验收。
触觉中心在实际运行的首个控制周期锁定，STOP 后重启重新锁定，重复 START 不改变当前中心。

上位机接管后会读取固件触觉参数；如仍显示旧值，使用“读取设备参数”同步。
选择所需模式后仍须应用模式再 START；本次未修改上位机的按钮流程。
STOP 会释放控制权并恢复默认主机限流，因此下一次试验应重新接管、应用模式并写回测试限流。

本次逻辑复查还修正了长期运行时的浮点位置分辨率损失与测速累计值有符号溢出。
参数含义、默认值、建议起点、限幅判断与曲线选择见 [触觉模式调参与逻辑检查说明](docs/触觉模式调参与逻辑检查说明.md)。
