# 无感启动、速度跟踪与抗干扰改进说明

日期：2026-09-20。本文先作为数据分析与改动设计报告，文末追加了本轮实际落地与验证结果。

## 1. 目标与结论

本次重点是：缩短可靠启动时间、改善实际速度跟随目标过慢和持续偏差、减少扰动引起的失锁。这里的“速度拟合”指速度闭环跟踪，不是对显示曲线做平滑拟合。

当前电机已经能够完成强拖、切换观测器并持续运行。首要改进应从速度环积分和接管连续性入手，而不是同时加大启动电流、PLL 和速度环全部增益。低速失锁机制需要补充观测数据后再调整。

主要依据：

- 本次无感闭环持续约 37.045 秒，最高目标 1200 rpm，说明系统已有可运行的基础。
- 速度 PI 的 Kp=0.0016、Ki=0.0001；积分计算已经乘 dt。其 Ti=Kp/Ki=16 秒，是速度误差消除慢的明确代码依据。
- 接管时直接将 Id、Iq 给定与速度积分清零，存在电流矢量和转矩衔接不连续的风险。
- 相位误差一次超限就失锁，当前没有相位失锁连续计数。把 lock_updates 改成 50 只是缩短锁定时间。
- 用户确认末尾为自行停机。低速观测失效是重点候选，但日志不足以区分相位超限、低 BEMF、主机心跳超时等具体触发原因。

## 4. 改动一：改善启动与无感接管

### 4.1 当前问题

`Motor_System_RunForcedStartup1ms()` 先以 Id 强拖；升速结束后只要 `Motor_Sensorless_IsReadyForHandover()` 有效就交接。交接执行 Id=0、Iq=0、主机 Iq=0、速度 PID_Reset，再立即切换角度源。

这会撤销维持运动的电流给定，让速度环重新建立输出。若开环角和观测角不一致，同样的 d/q 数值也不是同一个静止坐标电流矢量。不能将“强拖 Id=0.30 A”直接当作“真实转矩 Iq=0.30 A”。

过去依据粗略时间积分得出的精确交接角差（例如 0.29°）不宜作为验收证据：现有日志没有同拍开环角和交接事件时间。需要新增快照才能评估角度跳变。

### 4.2 建议实现

涉及 `motor_system.c`、`motor_current_loop.c/.h`、`motor_speed_loop.c/.h`。

1. 第一轮保持 500 ms、5 s、0.30 A、250 rpm，先实现交接连续性，避免同时改变启动斜坡和 PI。
2. 增加交接准备判据：连续 100 ms 观测有效且估算速度方向正确，速度与开环指令偏差不超过 max(30 rpm, 15%指令速度)。BEMF 还需达到进入阈值。100 ms 与速度容差均为首轮验证值。
3. 增加内部 HANDOVER 过渡阶段，初始时长 100 ms。不要把未完成的过渡提前发布为 COMPLETE；失锁仍进入停止路径。
4. 在电流 ISR 边界应用一个完整的交接请求，而非由 1 ms 任务分散写角度源、Id/Iq 和 PI 状态。只用短临界区发布请求；变换计算由 ISR 完成，不长时间关闭中断。
5. 交接时保存旧控制角与旧电流给定，先将旧 Id/Iq 逆 Park 到静止坐标，再按新控制角 Park 得到新 Id/Iq。按项目已有 Park 符号实现；用正反转和跨 2π 测试确认，不凭经验添加固定 90°。
6. 控制角从开环角连续过渡到观测角，角度差使用最短环绕差。过渡时旋转原有电流给定，使静止坐标矢量连续，再逐步过渡到 Id=0、Iq=速度环输出。
7. 处理电流 PI 积分输出的坐标变换，避免仅旋转给定而保持错误电压积分。具体使用项目逆 Park/Park 组合把旧积分电压矢量映射到新坐标，并按输出限幅约束。
8. 为速度环新增预置入口：`Motor_SpeedLoop_Preload(target_rpm, feedback_rpm, iq_pi_a)`，设积分为 `iq_pi_a - Kp*(target-feedback)`，再限幅；使用变换后带符号的 Iq 减去前馈，不能硬编码预置 0.30 A。
9. 平滑接管完成后才按现有目标斜率追踪主机目标。主机若要求 670 rpm，先完成交接再从当前工作点升速，避免多个瞬态叠加。

### 4.3 启动提速的后续实验

交接稳定后按 5 s → 4 s → 3 s 逐档缩短升速。每档正反各重复 10 次，记录成功率、最低 BEMF、交接角差和电流峰值。任一档重复失步则回到上档，不同时提高电流。250 rpm 的交接速度先保持；低速可运行边界不能仅由这一个日志确定。

## 5. 改动二：提高目标速度跟踪与负载恢复速度

### 5.1 定量解释

现有积分为：

```c
integral += ki * error_rpm * dt_sec;
output = kp * error_rpm + integral;
```

50 rpm 误差下，当前积分每秒只增加 0.005 A。补足额外 0.10 A，在误差恒定的简化假设下也需 20 秒；实际误差下降时积累还会更慢。该估算解释了慢收敛机制，不是电机真实调节时间预测。

Ti=Kp/Ki=16 s 也说明积分相对比例较弱。降速时，之前为高速维持而累积的积分需要缓慢下降，可以解释 190/150 rpm 平台偏快的一部分现象。

速度命令斜率不是长时间残差的主要解释：250→670 rpm 按 1000 rpm/s 只需 0.42 s，670→1200 rpm 需 0.53 s；日志与此一致。Iq 从 0 到 0.30 A 按 5 A/s 需 60 ms，也不能单独解释数秒至十几秒的收敛。

### 5.2 参数与代码建议

- 首轮保持 Kp=0.0016、Kd=0，仅将 Ki 从 0.0001 试调为 0.0010 A/(rpm·s)，Ti 变为 1.6 秒。此为待验证起点，不是已验证最优值。
- 如稳定但收敛仍慢，再试 Ki=0.0020（Ti=0.8 s）；每次仅改变一个参数。若低频摆动或过冲明显，应回退并检查反馈延迟、饱和及交接预置。
- 当前快变误差主要进入比例支路；若 Kp 后续增加，应先确认观测噪声不会让 Iq 抖动扩大，不按电机重量比例缩放 Kp。
- 保留目标速度斜率 1000 rpm/s、Iq 斜率 5 A/s 和现有限流作为首轮基线。若记录证明频繁命中斜率限制，再专门调整。
- 速度 PI 继续考虑前馈占用的电流余量。新增实际输出跟踪抗饱和，使积分知道经过限流、Iq 斜率和交接混合后的真正给定。

推荐的抗饱和形式：

```text
u_pi_raw = Kp * error + integral
u_total_requested = u_pi_raw + feedforward
u_total_applied = slew(clamp(u_total_requested))
u_pi_applied = u_total_applied - feedforward
integral += Ki * error * dt + (u_pi_applied - u_pi_raw) * dt / Tt
```

`Tt=0.1 s` 作为首轮起点。先实现明确的未限幅输出与已执行输出接口，避免把已经限幅的 PI 输出当作 raw。现有条件积分与回算不能未经设计重复叠加；采用回算版本时明确替代关系，只应用到 Speed，防止影响位置/电流环共用 PID。

### 5.3 反馈滤波与前馈

速度反馈先记录原始 PLL rpm 和实际送入速度 PI 的 rpm，再决定是否增加约 10 ms 的一阶低通。滤波系数按 `alpha=dt/(tau+dt)` 计算，1 ms 时约 0.091。仅滤速度外环反馈，不给 Park 电角度增加额外延迟；滤波后的延迟也必须纳入速度环测试。

本次摩擦前馈为零。先改进 PI，再用现有摩擦采样流程辨识；不要把平均 Iq 当作通用摩擦补偿，因为其中可能含负载和观测偏差。加速度前馈需已知惯量和转矩常数的定义，当前不直接添加。

## 6. 改动三：抗干扰和低速可用性

### 6.1 明确当前误差含义

`Motor_Sensorless_TrackPll()` 中，单位 BEMF 矢量与预测矢量叉积得到 `phase_error=sin(Δθ)`，它无量纲。当前 0.60 在局部对应约 36.87°，不是 0.60 rad。接近 180° 时正弦也接近零，因此仅看绝对叉积不足以排除反相锁定。

建议保留叉积作为 PLL 连续误差信号，同时增加点积 `cos(Δθ)` 用于锁定有效性，要求点积为正。配置注释明确为 sine-error；若改用 atan2 得到真实角误差，需要重新评估阈值和算力，不能悄悄替换。

### 6.2 锁定、相位失锁、低信号失锁分别计数

扩展 `MotorSensorlessConfig` 与内部计数器，建议首轮方案：

| 参数 | 验证起点 | 作用 |
|---|---:|---|
| lock_phase_error | 0.30，无量纲 | 新进入锁定使用较严格条件 |
| lock_updates | 100，约20 ms | 连续满足条件才锁定 |
| unlock_phase_error | 0.60，无量纲 | 已锁定状态的退出阈值 |
| unlock_updates | 50，约10 ms | 连续相位异常才失锁 |
| BEMF进入阈值 | 0.25 V | 防止刚越过噪声门槛即锁定 |
| BEMF退出阈值 | 0.20 V | 与进入阈值形成滞回 |
| 低BEMF退出计数 | 250，约50 ms | 先保持现有值，再依据数据评估 |

这些数值是一组隔离验证候选，不应在改速度 PI 的同一轮全部上线。50 ms 角度外推并不自动意味着足够可靠，需记录期间相位漂移。

状态规则：未锁定时只计进入条件；已锁定时正常样本清除连续异常计数；0.30～0.60 中间区保持锁定；点积为负也计相位异常；低 BEMF 使用独立计数，不在噪声主导时继续积分 PLL。NaN/Inf 作为明确故障立即退出。确认失锁后保持现有撤销 PWM 行为，不切回不存在的编码器。

不要仅把 0.20 V 门槛调低来让 150 rpm 运行。先测停机前 BEMF 和误差，若信号不足，滞回只能减轻抖动，不能创造可靠角度。暂不增加零速/低速无感能力承诺。

### 6.3 排查噪声来源

当前观测公式 `e=u-Ri-L·di/dt` 使用上一拍电压指令，而非实测端电压。按 L=97 µH、Ts=50 µs，单次电流差分增加 0.10 A 会贡献约 0.194 V 的原始电感项，量级接近最低 BEMF 门槛。低通会衰减其影响，因此不能直接推断一次尖峰就触发低 BEMF，但足以说明需检查采样质量。

先检查 ADC 触发相位、PWM开关边沿、同拍U/W数据、偏置及饱和，再评估死区与实际15 V母线偏差。避免在电流环前直接添加重低通。实际正常电流环整定在 `Motor_CurrentLoop_AutoTunePIDWithBandwidth()`，Kd=0；`pid.c` 另有 Kd=0.1 的通用函数，但不能据此声称当前运行电流环启用了微分。

PLL Kp=150、Ki=6000 第一轮保持。缺少 BEMF/相位日志时不要继续反复降低 PLL 带宽。软件记录还需区分“估计速度噪声”和“真实机械速度波动”。

## 7. 最小诊断与接口改动

改动首先服务于上述三项目标，不增加复杂自动恢复流程。

1. 在首次停止触发点锁存原因和时间，原因至少含主机STOP、心跳超时、启动超时、BEMF丢失、相位失锁、非有限数值、其他故障。停止清零不得覆盖首因，下一次显式启动才清除。
2. 停机快照记录角度来源、启动阶段、PLL rpm、BEMF幅值、叉积/点积、Id/Iq给定与实测、速度PI积分和限幅标志。ISR只保存小结构，不执行字符串格式化或USB发送。
3. 20 kHz ISR提供同拍调试快照，低频遥测复制快照再发包，避免多变量跨拍；测量新增ISR时长，维持50 µs预算。
4. 追加诊断遥测采用新schema，保留原28通道的索引和含义。优先新增BEMF、相位指标、原始PLL速度、外环反馈速度、请求目标/斜坡目标、PI积分、停机原因和交接阶段；按包容量拆分，不假设全部能装入原帧。
5. 上位机和CSV导出同时识别新schema；原schema仍可读取，缺失诊断值用缺失标记而非假零。日志旁保存固件标识、实际配置、采样周期，避免静默改变旧CSV表头含义。

## 8. 分步实施顺序

| 顺序 | 改动 | 保持固定的变量 | 目的 |
|---|---|---|---|
| 1 | 停机首因与必要遥测、同拍快照 | 所有控制参数 | 确认150 rpm自行停止原因 |
| 2 | 速度Ki试调0.0010 | Kp、PLL、5s启动、0.30A | 验证目标偏差是否更快消除 |
| 3 | 实际输出抗饱和 | 已通过的PI参数 | 改善降速与负载释放后的恢复 |
| 4 | 交接电流/电压状态连续、PI预置 | 交接250 rpm | 避免切换时转矩中断 |
| 5 | 独立相位失锁计数、BEMF滞回 | 已通过的启动/PI | 降低短扰动误停机 |
| 6 | 启动斜坡5→4→3s；必要时速度反馈滤波 | 每轮只变一个因素 | 提升启动速度并量化代价 |

每步保存版本与带时间戳CSV；如明显恶化，回退本步参数。不要将更宽松锁定和更强速度积分同时上线后仅凭“能转了”判定正确。

## 9. 验收指标与回归

以下为实验目标，而非现有性能承诺：

- 启动：正反转各10次全部进入无感闭环，无意外停机；记录定向、升速、交接总耗时，先确认5秒版本，再缩短。
- 速度跟踪：250→670、670→1200及反向降速；从斜坡目标到达后计时，500 ms滑动均值在2秒内进入 max(10 rpm,目标2%) 并维持至少1秒。对同一组条件比较PI改动前后，记录原始波动而非只比较平滑曲线。
- 过冲：以500 ms均值衡量，目标改变后过冲不超过阶跃幅度10%；不把单点PLL尖峰混同为机械过冲。
- 扰动恢复：先固定670 rpm，再进行可重复的受控负载施加/撤销，比较最大速度偏差、2秒恢复指标、Iq限幅时间和失锁事件。不得用日志缺失的负载信息推断抗扰性能。
- 低速边界：250→220→190→170→150 rpm分档，每档至少30秒，重复3轮；每次停止必须有原因和快照。在可靠速度区间内测试抗扰，不把一次150 rpm成功视为可靠最低转速。
- 软件测试：交接跨2π/正反转、完整电流矢量变换、PI预置限幅、连续异常计数恢复、低BEMF滞回、NaN/Inf、停机首因锁存、旧新遥测schema兼容。
- 编译：sensorless/sensored与UART/USB四种组合；检查Flash参数区边界、RAM与ISR时间。板上确认STOP和心跳超时仍及时停机。

## 10. 当前仍需确认的事实

实际烧录版本与工作树是否一致；150 rpm停止前的BEMF和相位误差；实际转子/负载惯量；物理轴速与PLL估计误差；供电及功率级电压余量；电流尖峰的同步采样真实性。它们决定后续最优参数，不能仅由当前CSV确定。

本文的优先结论是：速度积分偏弱有明确代码和日志支撑，应先做可量化的PI改进；启动交接存在明确的不连续实现，应改为同拍平滑过渡；抗干扰需要独立失锁判定与可追溯诊断，而不是只放宽一个阈值。

## 11. 2026-09-20 本轮实际实施

本轮在不提高启动电流、不缩短5秒斜坡、不修改PLL Kp/Ki的前提下，先实施直接针对“跟速慢、交接不连续、短扰动误失锁”的控制改动：

- 速度环 `Ki` 从 `0.0001` 调为 `0.0010 A/(rpm·s)`；Kp仍为`0.0016 A/rpm`。新增速度PI预置接口，按交接时Iq反算积分初值，不再在接管点清空速度积分。
- 交接前必须连续100 ms满足：观测器有效、状态为TRACKING、方向正确、PLL机械转速与强拖指令误差不超过`max(30 rpm, 15%)`。任何一项不满足，稳定计时重新开始；原2500 ms等待超时策略仍保持停机。
- 交接瞬间把开环坐标系中的Id/Iq目标和d/q电流PI积分电压旋转到PLL坐标系，保持定子电流及积分电压矢量连续；之后用100 ms将旋转后的Id/Iq线性过渡到`Id=0`和速度PI输出。
- BEMF锁定门槛改为进入0.25 V、保持0.20 V；锁定相位叉积阈值0.30，退出阈值0.60。进入锁定需连续100个5 kHz PLL更新（20 ms），相位失锁需连续50次越界（10 ms），低BEMF丢失仍需250次（50 ms）。
- 新增预测/实测BEMF单位矢量点积判据。进入锁定要求点积为正，避免叉积在相差约180°时也接近零造成假锁；点积持续非正也计入失锁。
- 对BEMF幅值、相位叉积和点积增加非有限数值检查。数值异常直接撤销观测有效状态，继续沿用系统现有的“无感角度失效即停PWM”策略。

本轮未实施诊断遥测schema和停机首因锁存，也未做速度环对实际斜率限幅后的回算抗饱和。这两项仍是下一轮定位150 rpm停止原因、改善大幅降速恢复的优先工作，不能由当前改动替代。
