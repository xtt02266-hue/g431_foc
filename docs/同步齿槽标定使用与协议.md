# 同步齿槽标定（固件 1.7.1 / Studio 0.8）

1.7.1 修复同步采集时UART只在空闲后组包造成的发送空隙：增加独立低优先级待发包，在DMA发送期间准备下一包，完成中断优先发送命令应答，再接续数据包；CRC改为相同多项式的4位查表，保持帧和校验结果不变。采集仍为1kHz，64条记录缓冲及溢出停机保护不变。新增实际发送函数的本机模拟测试，覆盖1kHz数据、普通遥测、状态及心跳并发；串口持续吞吐仍需实机确认。

## 使用顺序

1. 更新固件，直接运行更新后的上位机源码。无需重新打包 EXE。
2. STOPPED 状态下接管控制，展开“同步齿槽标定”。新功能依赖 HELLO 能力 bit9；旧固件会明确显示缺少能力。
3. 点击“自动标定：60 / 80 / 100 rpm 正反转”。电机会自动旋转、减速、换向。摩擦补偿保留当前设置；齿槽补偿在采集期间自动关闭。不要手动带负载或握住转子。
4. 等待后台质量分析。每个会话自动保存在上位机目录 `calibration_runs/日期时间_会话号/`。点击质量报告查看具体拒绝原因。
5. 通过后候选表载入编辑区，初始建议增益 0.3、最大补偿 0.010 A、相位 0。依次点击“上传到RAM试用”“写入补偿配置”“RAM验证：关闭→开启→关闭”。这些步骤都需要停机并拥有控制权。
6. RAM 对照通过后，在 Free 模式确认手感且无异常自转/振动，STOP，再接管控制、勾选手感确认，最后手动保存 Flash。保存前会重新读取配置和 LUT 身份；配置改变后必须重做对照。

STOP 或“中止自动流程并停机”随时可用，取消后不会继续后续速度或对照。中断记录仍保存，但不能生成合格 LUT。连接本身不会启动电机，也不会自动上传、写 Flash。

旧原始 CSV 保留诊断/预览功能，但缺少同步时间、最终给定、实测电流和传感器状态，不能用于新的正式生成流程。旧 LUT CSV 仍可导入 RAM，保存 Flash 同样需要对照。

## 自动采集

- 固定尝试 60、80、100 rpm，逐档正转、反转，不使用可能停转的 20/50 rpm。
- 速度斜率 30 rpm/s；采集电流上限为原会话上限与 0.20 A 的较小者，不自动提高电流限值。
- 每方向至少等待 5 秒、转过 5 圈，并满足连续 2 秒稳速；20 秒未稳定则退出该档。
- 记录 14 个在线合格圈（含边界余量），离线至少需要 12 个完整合格圈。最长采集 90 秒/方向。
- 每次换向、换档先减速至零，实际转速 <2 rpm、已应用目标 <0.1 rpm 持续 500 ms 才进入下一阶段。减速超过 10 秒终止整个会话。
- 已到目标速度后，方向速度 <5 rpm 持续 50 ms 判为停顿：当前速度失败，减速后尝试下一速度。传感器失效、控制权丢失、通信超时或同步缓冲溢出终止会话。
- 至少两档速度正反方向完整通过才算采集完成。固件“完成”仅表示在线采集完成，仍须离线检查，不能直接视为 LUT 合格。
- 会话结束后停止输出并恢复原模式、输入源、电流上限、速度斜率、齿槽补偿配置；不会恢复运行或旧目标速度。
- “自动诊断采集”允许不稳定速度进入记录，仍有停顿、超时和失控保护。诊断不会生成 LUT，适合查看一直无法稳速的原因。

## 同步和质量检查

控制任务每 1 ms 发布一次目标、速度窗、PI/前馈、限幅标记和传感器状态；紧随其后的 ADC/FOC 中断将其与本次 Park 使用的原始机械角度、实际 Iq/Id、最终 Iq 给定组合成记录。每控制周期最多一条。Uq 是该 ADC 中断更新 PI 之前的输出。时间戳来自控制任务，速度估计仍有自适应窗口和滤波延迟；同步不等于消除了速度估计延迟。

每个完整圈检查：

| 项目 | 门槛 |
|---|---|
| 平均速度偏差 | ≤ max(0.5 rpm, 目标的 2%) |
| 速度误差 RMS | ≤ max(0.5 rpm, 目标的 3%) |
| 速度误差绝对值 P95 | ≤ max(1 rpm, 目标的 8%)；固件在线使用更保守的峰值门槛 |
| 停顿、反向、限流、Iq 斜率限制、同步序号间断 | 整圈拒绝 |
| 编码器告警、数据年龄 >2 ms、CRC/传输错误新增 | 整圈拒绝 |
| 单圈角度覆盖 | ≥95% |
| Iq 跟踪误差 RMS | 同样的 5 点对称滤波后 ≤ max(2 mA, 该圈给定交流 RMS 的 20%) |

每速度/方向还要求至少 12 圈、累计覆盖 ≥99%、每格实际样本 ≥12、逐圈中位相关系数 ≥0.8、信号/圈间误差 ≥3；最终给定与实测 Iq 的位置曲线需一致。拒绝样本不从原始文件删除。

从最终给定减去已施加的摩擦前馈，按机械角度形成 512 格曲线，去除每圈直流量，再按同一机械角度平均正反转曲线。**不搜索 ±64 格相位，不反转电流符号来强行对齐。**至少两档正反转均合格，各档合成曲线相关系数 ≥0.8、RMS 比值 0.8～1.25，才形成候选表。

名义惯量与转矩常数用于保守的动态污染检查：10 ms 速度差分对应的电流 RMS 不得超过 max(0.5 mA, 位置曲线 RMS 的 10%)。它不是独立测得的加速度，不用于反演齿槽转矩。速度和位置均来自同一个编码器；编码器误差仍可能形成重复波形，跨速一致性也不能单独证明物理齿槽转矩。

如果失败，先看报告：稳速失败/停顿意味着该速度和现有控制参数不适合标定；传感器告警需要检查角度链路；电流跟踪失败应先处理电流环；跨速度不一致或动态污染提示数据还包含动态响应。不要通过放大增益或放宽相位搜索绕过检查。

## RAM 对照和保存

对照自动执行 OFF / ON / OFF 三个会话，每次依然覆盖三档正反转；三个会话使用同一配置及 LUT。比较最低一个既有充足合格圈、又低于补偿关闭速度的速度档，避免选择性挑选最好结果。

- 对照开始要求设备已启用齿槽配置、增益 (0,1]、最大补偿 (0,0.010] A、有效 LUT 版本；固件同时校验。
- 每方向每会话至少 10 个合格圈；任一会话中断/丢包不通过。
- 关闭基线 RMS ≥0.5 rpm，前后基线差 ≤max(0.1 rpm, 基线的 10%)。
- 开启后速度误差 RMS 至少降低 15%，两个方向都需满足；实际补偿 RMS 至少 0.1 mA。
- Iq 跟踪误差不超过关闭值的 1.1 倍 +1 mA，峰值给定不超过关闭值的 1.1 倍 +2 mA。
- `comparison.json` 保存结果与三个原始会话目录。不通过时可继续 RAM 诊断，但上位机禁止保存 Flash。
- 保存门槛是新上位机的流程约束；旧上位机的既有 Flash 命令仍兼容，固件并不声称持久保存了分析授权。

## 新增线协议（旧命令/普通遥测不变）

HELLO：当前固件版本 1.11.0，普通遥测 schema 7（29 floats），特性 bit9 = 同步齿槽标定、bit10 = 自动摩擦采集、bit11 = 摩擦参数Flash保存、bit12 = 速度PI在线调试、bit13 = 逐点齿槽标定。保留协议 framing v2 和既有 bit8 十倍增益能力。普通遥测正常 200 Hz，标定/排空期间 20 Hz。串口仍为 921600 baud。

所有整数 little-endian，浮点 IEEE754 float32。

| 命令 | 请求 body | 响应 body |
|---|---|---|
| 0x31 CAL_INFO | 空 | 176 字节元数据 |
| 0x32 CAL_START | 1 字节 mode：0诊断、1齿槽标定、2对照OFF、3对照ON、4自动摩擦采集（需bit10）、5逐点齿槽标定（需bit13） | 32 字节状态 |
| 0x33 CAL_ABORT | 空 | 32 字节状态，停止并恢复配置 |
| 0x34 CAL_STATUS | 空 | 32 字节状态 |

START 需要 HOST + STOPPED + 有效参数及新鲜编码器，且无未排空旧记录。自动流程中禁止修改配置，读状态、心跳、STOP、释放控制、中止仍有效。START 应答重试走既有去重缓存。

状态格式 `<III4BHH5B3xf`：session、produced、dropped；phase/reason/speed_index/reverse；当前方向 accepted/rejected 圈数；passed_mask/mode/三档失败原因；3 字节保留；target_rpm。phase=0未开始、1稳速、2采集、3减速、4完成、5失败、6取消。reason=0正常、1不稳定、2停顿、3传感器、4缓冲溢出、5取消、6减速超时、7不足两档、8控制中断。

新增 packet type=5，payload 头 `<HIBBI`：schema u16=1、session u32、count u8 (1～3)、保留0、dropped u32，随后 count 条64字节记录。通常每3条成包，终止后发送尾包，队列成功接收才消费环形缓冲。64条环形缓冲占4 KiB，ISR不做串口发送。

记录格式 `<IIHH10fBBHII`：sequence、tick_ms；angle15bit、flags；target_rpm、speed_rpm、window_rpm、pi_iq、friction_iq、cogging_iq、applied_iq、actual_iq、actual_id、uq；sensor_status、window_ticks；sensor_age_ms；crc_errors、transfer_errors。flags bits0～3=限幅/Iq斜率限制/传感器时效/控制周期遗漏，bits8～10=阶段，bits11～12=速度索引，bit13=反向。Iq 保持固件电磁方向符号，绝不因反转取绝对值。

元数据：0～11 `<HHIHbB`（schema、记录大小、配置版本、极对数、UVW方向、摩擦/齿槽启用位）；12～139 为上位机 `calibration.INFO_FIELDS` 定义的32个 float；140 mode、141 source、142 telemetry schema u16；144～167 编译日期时间ASCII；168 LUT版本u32，172 LUT CRC u32。上位机保存启动前元数据，并在启动后再次读入实际电流环参数作为 `active_config`，校验配置版本只增加1。

## 文件与验证范围

会话包含 `samples.csv`、`metadata.json`、`analysis.json`；合格会话另有 `candidate_lut.csv`。导入会话会重新计算，不能通过修改 analysis.json 绕过检查。旧原始CSV缺少必要信息，不自动升级为同步记录。

软件测试包括序列化、分包/截断、完整/中断记录、速度停顿、传感器告警、电流跟踪、正反转/跨速度质量、旧固件门控、终止收包和STOP取消。C 状态机测试位于 `refactor_validation/calibration/test_calibration.c`。编译不等于实机验证；UART持续吞吐、ISR时序、实测电流噪声及补偿收益仍需在电机上确认。
