# 速度环 PI 在线调试（固件 1.10.0）

## 操作

1. 烧录 1.10.0 固件，重启上位机并重新连接、接管控制。
2. 在日常控制中选择 Speed；点击“读取速度环PI”，从设备读取当前值。必须读过才能应用，避免把界面默认值误写入。
3. 调整 Kp、Ki，点击“应用速度环PI”。停机时可写入；运行中仅 Speed＋HOST 支持写入。输入框修改本身不会发送命令。
4. 界面“设备生效”显示最后一次成功读取/写入确认的 Kp、Ki、Kd。Kd 只读，保持固件原值。查看实际速度和电流曲线，逐项调参。
5. 自动摩擦/齿槽采集和质量分析期间冻结写入；完成后才能继续调参。普通 STOP 保持有效。

单位为 Kp：A/rpm、Ki：A/(rpm·s)。Ki 已由固件乘以1ms控制周期，输入时不要再乘采样周期。范围 Kp 0～0.1，Ki 0～1；这些是协议范围，不表示任意值都适合当前电机。

运行中修改 Kp 时，积分电流增加 `(旧Kp-新Kp)*当前误差`，保持更新瞬间 P+I 电流尽量连续，并按现有积分限幅夹紧；积分限幅生效时仍可能有变化。Ki 修改保留当前积分贡献，Ki=0 表示不再累计积分。停机修改时清空积分及历史状态。

仅RAM生效，重启恢复源码中 `MOTOR_SPEED_PID_KP/KI` 默认值；STOP、切模式或自动标定不会恢复这些增益。当前功能不改变测速滤波、电流限幅、摩擦/齿槽参数、Kd或默认增益。

60rpm齿槽采集稳速入口要求连续2秒在58.2～61.8rpm。每圈质量还要求平均误差≤1.2rpm、误差RMS≤1.8rpm、峰值偏差≤4.8rpm；上位机另有覆盖率、电流跟踪、重复性和跨速度一致性检查。通过稳速不等于已经获得准确LUT。

## 协议兼容

HELLO固件版本1.10.0，能力bit12（0x1000）为速度PI读写，总能力0x1FFF。协议framing v2、普通遥测schema7及已有命令保持不变。

| 命令 | 请求body | 成功响应body |
|---|---|---|
| 0x36 SET_SPEED_PI | 8字节 `<ff>` Kp、Ki | 12字节 `<fff>` 当前Kp、Ki、Kd |
| 0x37 GET_SPEED_PI | 空 | 12字节 `<fff>` 当前Kp、Ki、Kd |

沿用HOST令牌、命令确认、去重与重试。写入需HOST，且STOPPED或SENSORED_RUN＋SPEED＋HOST输入；自动采集期间返回BUSY。非法长度、非有限数、负值或越界参数拒绝，不更新参数或配置版本。成功原子更新两个增益并增加配置版本，标定元数据包含生效增益。读取可在自动采集期间进行。

新上位机连接不含bit12的旧固件时禁用PI按钮并提示升级；原有速度控制仍可用。旧上位机可继续控制新固件，原有协议不变。

测试包含真实固件函数的更新瞬间输出连续性、积分限幅、停机重置、非法值、所有权、模式及自动采集门控；上位机测试覆盖精确载荷、旧固件、读后写、运行模式和断线失效。实机效果需要烧录后观察。
