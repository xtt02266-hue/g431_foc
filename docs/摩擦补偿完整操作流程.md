# 摩擦补偿完整操作流程

日期：2026-09-15  
适用固件：`D:/WorkDocument/g431_foc`  
适用上位机：`D:/WorkDocument/HapticKnobStudio`

## 1. 目标和实施顺序

本流程用于解决低速运行时由静摩擦造成的“粘住—积分累积—突然挣脱—超速—再次粘住”现象。

推荐顺序：

```text
确认电流环和编码器正常
→ 调整速度PI基线
→ 完成摩擦补偿
→ 验证Speed和Free
→ 最后标定齿槽补偿
```

摩擦补偿应先于齿槽补偿。摩擦属于方向相关的低频分量；先稳定摩擦补偿，后续正反转合成的齿槽LUT会更干净。

## 2. 当前代码状态

当前代码已经实现：

- Speed模式根据斜坡后的目标速度提前输出摩擦前馈；电机尚未转动时也能获得起步电流。
- Free模式根据实际速度输出摩擦补偿，静止时保持零输出。
- Speed模式的最终Iq使用`5 A/s`变化率，便于闭环及时从驱动切换到制动；Free触觉仍使用较柔和的`1 A/s`。
- 速度目标停止或换向时清除旧方向积分。
- 速度PI的输出范围会扣除摩擦和齿槽前馈占用的电流余量，减少积分饱和。
- 上位机可以读取摩擦配置、采集多档正反转数据、导入/导出CSV、自动拟合、预览并写入参数。
- 使用初步摩擦补偿复测时，拟合程序使用`speed_loop_iq + friction_iq`还原总摩擦电流。

当前摩擦模型：

```text
Iq_friction = Ic × tanh(rpm / smooth_rpm) + Kv × rpm
```

参数含义：

| 参数 | 含义 |
|---|---|
| `Ic` | 库仑摩擦电流，决定离开零速后的主要补偿幅值 |
| `Kv` | 粘性摩擦系数，描述摩擦随速度增加的部分 |
| `smooth_rpm` | 零速附近的平滑速度；越小，静摩擦补偿建立越快 |
| `max_iq` | 摩擦补偿自身的独立电流上限 |

当前代码使用的速度环参数为：

```c
#define MOTOR_SPEED_PID_KP  0.0016f
#define MOTOR_SPEED_PID_KI  0.0001f
#define MOTOR_SPEED_PID_KD  0.0f
```

这是启用摩擦前馈、Speed专用`5 A/s`Iq变化率和20/10/5 ms自适应滚动测速窗后的已验证稳定基线。低Ki避免积分重新承担静摩擦电流。在排除编码器角度周期误差之前，不继续提高Kp。

速度反馈使用MT6826S 15位SPI角度连续展开位置和20/10/5 ms滚动窗计算，始终每1 ms发布一次。低速20 ms窗口的分辨率约为`0.0916 rpm/count`，中高速缩短窗口以减少延迟；窗口切换带迟滞，不会在临界转速附近反复跳变。

## 3. 安全准备

1. 电机保持无外加负载。
2. 确保旋钮和机械结构不会在突然转动时碰撞。
3. 首次测试使用`Iq_limit=0.10 A`。
4. 齿槽补偿在整个摩擦标定阶段保持关闭。
5. 每次修改模式、限流或补偿参数前先STOP。
6. STOP会释放HOST控制权，之后需要重新点击“接管控制”。


换向前先发送`0 rpm`，等待电机基本停止。

### 7.4 预期结果

以`+5 rpm`为例：

- CH12应在起步时立即产生正向摩擦补偿。
- 使用当前参数时，CH12应逐渐接近约`+0.027 A`。
- CH11只修正模型残差，不应连续几十秒爬升。
- CH8不应长期顶住`0.10 A`限流。
- 实际速度应减少长时间停住后突然加速的现象。

负转时CH12应反向。

## 8. 根据曲线定位问题

| 现象 | 主要原因 | 调整方式 |
|---|---|---|
| 电机卡住，CH11缓慢增加且没有到上限 | 摩擦前馈不足或Ki太小 | 先确认新固件和CH12；再将Ic提高约10% |
| CH8持续达到0.10 A，速度仍不足 | 总限流不足或机械阻力异常 | 检查外载、卡涩、相序、零位和实际Iq跟随 |
| 快速来回抖动，且最终Iq已能反向制动 | Kp偏高 | `0.0018 → 0.0016 → 0.0014` |
| 缓慢周期性忽快忽慢 | Ki偏高或仍有粘滑极限环 | `0.0001 → 0.00005` |
| 超调时最终Iq始终不反向制动 | Kp偏低 | `0.0018 → 0.0020`，同时确认中高速测速窗已经缩短 |
| 长期存在稳态误差且CH11未饱和 | Ki偏低 | `0.0001 → 0.0002 → 0.0003` |
| CH12起步时仍为0 | 固件未更新或摩擦配置未启用 | 重新烧录并读取配置确认 |

不要同时大幅修改Kp、Ki和Ic。每次只改一类参数，保留对应CSV和曲线。

## 9. 正式采集低速摩擦数据

第一版补偿使低速可以连续转动后，再进行正式拟合。

推荐速度：

```text
±5 rpm
±10 rpm
±20 rpm
```

如果5 rpm仍无法稳定，先采：

```text
±10 rpm
±20 rpm
±40 rpm
```

稳定后再补采±5 rpm。

### 9.1 采样步骤

1. 齿槽补偿保持关闭。
2. 摩擦补偿可以保持启用。
3. 进入Speed模式并START。
4. 点击“开始记录各档稳态数据”。
5. 发送第一个正向速度。
6. 等待过渡完成并稳定采满至少2个机械圈。
7. 发送`0 rpm`并等待停止。
8. 发送对应负向速度并同样采满至少2圈。
9. 完成至少三组正负配对速度。
10. 点击“停止记录”。
11. 点击“导出摩擦采样CSV”保存原始数据。

建议每档记录时间：

| 速度 | 两圈时间 | 建议总时间 |
|---:|---:|---:|
| 5 rpm | 24秒 | 26～30秒 |
| 10 rpm | 12秒 | 14～17秒 |
| 20 rpm | 6秒 | 8～10秒 |
| 40 rpm | 3秒 | 5～7秒 |

上位机会自动丢弃每档前1.5秒，并只保留：

```text
目标速度已经到位
方向正确
实际速度误差 <= max(3 rpm, 目标速度25%)
```

启用第一版摩擦补偿复测时，拟合输入为：

```text
总摩擦Iq = speed_loop_iq + friction_iq
```

因此CH11只剩残差也不会导致摩擦量被低估。

## 10. 拟合和质量判断

1. 点击“拟合摩擦参数”。
2. 点击“预览采样与拟合”。
3. 检查正转点、反转点和拟合曲线。

建议接受标准：

```text
R² > 0.95
RMSE < 0.001 A
正反方向不对称度 < 10%
```

如果正反不对称度明显超过10%，检查：

- 是否存在外加负载；
- 线缆是否只在一个方向拖拽；
- 轴承或结构是否方向性卡涩；
- 正反转采样时电机温度是否差异过大。

## 12. Speed验收

建议测试：

```text
±3 rpm
±5 rpm
±10 rpm
±20 rpm
```

目标表现：

```text
CH12承担主要稳态摩擦电流
CH11只保留较小残差
CH8不持续限流
实际速度不再出现明显粘住—挣脱周期
停止和换向没有明显积分冲击
```

如果`smooth=1 rpm`时Speed效果好，可以先保留该值完成Speed验收，再单独检查Free模式。

## 13. Free模式验收

1. STOP。
2. 重新接管控制。
3. 应用Free模式。
4. START。
5. 松手观察电机是否保持静止。
6. 用手缓慢正反转旋钮，检查阻力是否减小且方向正确。

如果松手后自行转动或零速抖动：

1. 将`smooth`从1提高到`3～5 rpm`；
2. 或将`Ic`降低5%～10%；
3. 将摩擦独立限幅暂时降至`0.03 A`；
4. 写入参数后重新START测试。

Speed使用目标速度计算摩擦，Free使用实际速度计算摩擦，因此两者在零速附近的表现不同。当前两种模式共用同一个`smooth`参数，需要在Speed可靠起步和Free静止稳定之间选择合适值。

## 14. 最后进行齿槽补偿

摩擦补偿验收通过后：

1. 保持摩擦补偿启用。
2. 关闭齿槽补偿。
3. 使用Speed模式以`+20 rpm`采样6圈。
4. 使用Speed模式以`-20 rpm`采样6圈。
5. 生成512点齿槽LUT并检查预览。
6. 上传到RAM试用。
7. 完成补偿前后对比。
8. 确认后保存到Flash。
