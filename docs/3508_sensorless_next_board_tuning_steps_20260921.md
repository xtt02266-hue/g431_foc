# 3508 无感控制下一块板调试与代码改进步骤

## 1. 文档目的

本文记录当前 `codex/sensorless` 分支的可复现基线、已发现的问题和下一块板的调试顺序。

调试顺序必须保持为：

```text
硬件与供电
  → U/W 电流零点和增益
  → ADC/PWM 采样时刻
  → 无感角与 dq 电流谐波
  → PLL
  → 速度滤波和速度 PI
  → 高速与扰动测试
```

如果前一级没有确认，不应通过提高后一级增益掩盖问题。

## 2. 当前代码基线

### 2.1 电机和供电

- 电机：3508，已拆除减速器。
- 供电：固定 15 V。
- 相电阻：0.194 Ω。
- 相电感：0.097 mH。
- 极对数：7。
- 电流采样：PA0 为 U 相，PA2 为 W 相。
- 分流电阻：0.016 Ω。
- 标称运放增益：20。

### 2.2 当前待提交参数

```text
TIM1 CH4 ADC触发 Pulse       50
强拖对准时间                 250 ms
强拖加速时间                 2000 ms
等待锁定超时                 2000 ms
默认交接速度                 250 rpm
强拖电流                     0.40 A
电流环控制带宽               450 Hz
速度环 Kp                    0.004 A/rpm
速度环 Ki                    0.003 A/(rpm·s)
速度环输出范围               ±3.0 A
电流 ADC 一阶滤波 alpha      0.25
PLL Kp                       150
PLL Ki                       6000
PLL运行频率                  5 kHz
```

注意：速度环的 `±3.0 A` 输出限制不等于最终一定输出 3 A。实际仍受到上位机运行电流限制、系统硬限流和母线能力限制。但是对新板初次测试时，上位机电流限制应先设为 0.4 A，不要直接使用高电流。

### 2.3 当前参数风险

当前速度 PI 的 `Kp=0.004`、`Ki=0.003` 比前一版明显更激进。它可能改善扰动恢复，也可能放大 PLL 速度噪声和约 12～16 Hz 的闭环摆动。

下一块板不应直接用该参数高速运行。应先确认电流采样，再按本文第 7 节重新确定速度 PI。

## 3. ADC 采样点已有结论

已比较三个 TIM1 CH4 Pulse：

```text
Pulse = 5
Pulse = 50
Pulse = 4000
```

### 3.1 Pulse=4000

`Pulse=4000` 应排除。1500/1800 rpm 下出现以下现象：

- 转速标准差约为 `Pulse=5` 的 1.8～2.0 倍。
- Iq、Id 标准差增加约 30%～42%。
- 速度环 12～15 Hz 输出摆动增加约一倍。
- U/W 相电流基波相位间隔由接近 120° 变成约 64°。
- dq 轴二倍电频分量明显增加。

原因很可能是采样点接近高占空比时的相桥换相位置。U/W 是 ADC 顺序转换，两个通道可能分别落在换相前后。

### 3.2 Pulse=5 和 Pulse=50

两者非常接近：

- `Pulse=50` 的总体转速标准差和平均误差略低。
- `Pulse=5` 的 10～20 Hz 窄带速度摆动和 dq 二倍电频略低。
- U/W 相位关系都约为 128°～130°，明显优于4000。

当前代码暂时保存 `Pulse=50`，因为它离计数器谷底多留出约 0.29 µs，同时总体 RMS 指标没有恶化。但目前没有足够重复试验证明50一定优于5。

### 3.3 下一步采样点扫描

按以下顺序测试：

```text
5 → 100 → 5 → 200 → 5
```

使用 A/B/A 顺序是为了排除电机温升、轴承温度和供电变化。

每个固件执行相同工况：

1. 上电后静置30秒。
2. 上位机电流限制设为0.4 A。
3. 强拖启动并切入无感。
4. 1500 rpm保持5秒。
5. 1800 rpm保持5秒。
6. 条件允许时2500 rpm保持5秒。
7. 导出带时间戳CSV。
8. 停机并等待电机温度接近下一次测试条件。

选择采样点时按以下优先级：

1. U/W相位间隔接近120°。
2. U/W基波幅值差小。
3. Id RMS小。
4. Iq跟踪误差RMS小。
5. dq二倍电频分量小。
6. 10～20 Hz速度摆动小。

不要只根据曲线看起来是否平滑做判断。

## 4. 新板 U/W 电流采样检查

### 4.1 上电静态检查

电机先不启动：

1. 限流电源设为15 V，并限制输入电流。
2. 不接电机或保持PWM关闭。
3. 测量PA0、PA2电压。
4. 两路都应接近中点电压，且远离0 V和3.3 V。
5. 上位机记录10秒：
   - U相电流。
   - W相电流。
   - U相运放输出。
   - W相运放输出。

当前换算关系：

```text
电流灵敏度 = 0.016 Ω × 20 = 0.32 V/A
12位 ADC 每计数 = 3.3/4095 = 0.806 mV
每 ADC count 约对应 2.52 mA
```

建议判据：

- 自动零点校准后，U/W平均电流在 ±0.02 A 内。
- 静止电流标准差小于约0.01～0.02 A。
- 多次上电的零点电压变化小于约10 mV。
- 单路明显比另一通道噪声大时先查硬件，不调PI。

### 4.2 增益检查

固定转子，使用固定开环电角度和小电流，依次测试：

```text
+0.10 A
+0.20 A
+0.40 A
-0.10 A
-0.20 A
-0.40 A
```

用电流钳或串联电流表读取实际电流，并记录两路运放电压。分别计算：

```text
GainU = |ΔVU| / (|ΔI| × 0.016)
GainW = |ΔVW| / (|ΔI| × 0.016)
```

目标值约20。U/W增益差建议小于2%，最多不超过3%。正负方向斜率应基本一致。

如果增益差稳定存在，应在代码中增加 `gain_u`、`gain_w` 两路独立参数。零点独立校准不能修复增益误差。

## 5. 示波器确认 ADC/PWM 时序

推荐通道：

```text
CH1  一路PWM逻辑或栅极驱动输入
CH2  PA0，U相运放输出
CH3  PA2，W相运放输出
CH4  ADC回调调试GPIO
```

普通示波器地夹只能接 DGND。不要把普通地夹接到电机相线或半桥开关节点。测相电压必须使用差分或隔离探头。

在 ADC 注入转换回调入口拉高调试GPIO，读取完成后拉低。用2～5 µs/div观察：

- 采样是否落在运放输出平坦区。
- 是否靠近PWM翻转尖峰。
- U/W顺序转换期间是否跨越开关边沿。
- 高占空比时稳定窗口是否缩短或消失。

如果固定 Pulse 无法覆盖全部占空比，后续需要按三相占空比动态选择采样窗口，而不是继续扩大固定Pulse。

## 6. 无感角和电流谐波检查

### 6.1 当前限制

无编码器板上的 `AS5600参考角有效` 为0，因此不能计算真正的绝对角误差。

下一版遥测建议增加：

- `pll_phase_error`。
- `pll_phase_alignment`。
- `bemf_alpha_volts`。
- `bemf_beta_volts`。
- PLL原始机械速度。
- 送入速度PI的滤波后机械速度。

其中 `pll_phase_error` 是观测器内部残差，不等同于独立编码器真值，但可以判断PLL是否存在与电频同步的周期误差。

### 6.2 测试速度

七极对电机的电频为：

```text
fe = mechanical_rpm × 7 / 60
```

典型值：

```text
1500 rpm → 175 Hz
1800 rpm → 210 Hz
2500 rpm → 291.7 Hz
3500 rpm → 408.3 Hz
```

当前1 kHz遥测可以观察408 Hz是否存在，但已经接近500 Hz奈奎斯特频率，幅值和相位精度有限。进行角误差和相干性分析时，建议USB CDC遥测提高到至少2 kHz，最好5 kHz。

### 6.3 判据

- PLL相位误差和Iq/Id在同一电频出现稳定相位关系：优先检查观测器延迟、R/L参数和PLL。
- 角误差较小，但dq二倍电频明显：优先检查U/W增益和采样时刻。
- 只有速度和速度环Iq存在12～16 Hz：优先检查外速度环和机械系统。
- 正反转后误差符号反向：优先检查采样、滤波或计算延迟。
- 总是同一个物理通道异常：优先检查运放、分流电阻和ADC输入。

## 7. 速度反馈和速度 PI 改进

### 7.1 现有结构问题

无感接管后，速度环直接使用PLL输出的机械速度。编码器路径的：

```c
Motor_SpeedEstimator_Init(0.4f);
```

不会对无感速度生效。因此只修改该0.4不能改善纯无感运行。

### 7.2 增加无感速度滤波

在1 kHz系统任务中为PLL机械速度增加独立一阶滤波，只将滤波结果送给速度PI：

```text
filtered += alpha × (raw - filtered)
```

初始建议：

```text
alpha = 0.20～0.30
```

不要一开始使用0.05～0.10。过重滤波会在12～16 Hz附近增加明显相位滞后，可能使速度闭环更不稳定。

滤波状态必须在以下情况重置到当前原始速度：

- STOP。
- 强拖切换到无感。
- 转向改变。
- PLL失锁或重新启动。

遥测应同时保留PLL原始速度和PI滤波速度，避免把真实摆动误判为显示噪声。

### 7.3 重新确定速度 PI

先完成电流采样和PLL速度滤波，再调速度PI。调试期间：

- 电流环保持450 Hz不变。
- 摩擦补偿关闭。
- 齿槽补偿关闭。
- 运行限流先设0.4～0.6 A。
- 一次只修改一个参数。

第一阶段关闭积分：

```text
Kp = 0.0015
Ki = 0
```

按以下顺序提高Kp：

```text
0.0015 → 0.0018 → 0.0020 → 0.0022 → 0.0025 → 0.0030
```

找到开始持续产生12～16 Hz摆动的点，再退回约20%。不要默认使用当前 `Kp=0.004`。

Kp确定后再加Ki：

```text
0.0003 → 0.0005 → 0.0008 → 0.0010 → 0.0015
```

Ki只用于消除稳态误差，不应用来加快起步。

每组参数测试：

```text
1000 rpm 5秒
1500 rpm 5秒
1800 rpm 5秒
2500 rpm 5秒
目标速度阶跃 1000→1800 rpm
轻微手动扰动后释放
```

建议验收条件：

- 1800 rpm稳态速度标准差小于约8 rpm。
- 高速稳态速度标准差小于15～20 rpm。
- 12～16 Hz速度谱线相对当前至少降低一半。
- Id RMS逐步压低到0.15～0.20 A以下。
- 阶跃超调小于10%。
- 扰动后0.5～1秒恢复且无持续振荡。

## 8. PLL调试顺序

当前PLL参数：

```text
Kp = 150
Ki = 6000
BEMF滤波 alpha = 0.05
PLL更新频率 = 5 kHz
```

只有在以下条件满足后才调整PLL：

1. U/W零点和增益已确认。
2. ADC采样点已确定。
3. dq二倍电频已降到可接受范围。
4. 电机R/L参数与实际电机一致。

调PLL时保持速度PI较弱，先固定Ki，只扫描Kp：

```text
100 → 120 → 150 → 180
```

再固定Kp扫描Ki：

```text
3000 → 4000 → 5000 → 6000
```

观察：

- `pll_phase_error` RMS。
- 无感速度噪声。
- 交接是否稳定。
- Id RMS。
- 正反转是否一致。
- 低速扰动后是否失锁。

如果降低PLL增益后速度更平滑但角度明显滞后、Id增大，说明PLL过慢；如果PLL速度和Iq出现高频噪声，说明PLL过快或BEMF输入过脏。

## 9. 下一块板首次启动清单

### 9.1 不接电机

- 检查15 V、5 V、3.3 V电源。
- 检查USB CDC是否枚举和稳定通信。
- 检查PA0/PA2静态电压。
- 检查PWM关闭时三相输出状态。
- 检查三相门极无直通。

### 9.2 接电机但不启动

- 上位机运行电流限制设为0.4 A。
- 记录U/W零点10秒。
- 手动转动电机，确认没有异常短路阻力。
- 确认极对数为7。
- 确认相序方向参数。

### 9.3 首次强拖

- 电源限流。
- 电机固定可靠，周围无人员和线缆。
- 目标速度先设500～800 rpm。
- 点击START，观察对准、加速、等待PLL、交接状态。
- 如果不能锁定或方向错误，直接STOP，不提高电流硬拖。

### 9.4 分级提速

```text
800 → 1000 → 1500 → 1800 → 2500 → 3000 rpm
```

每一级检查：

- 无感角有效状态。
- Iq/Id峰值和RMS。
- U/W运放是否接近电源轨。
- USB是否掉线。
- 驱动器和电机温度。
- 是否出现固定频率噪声或机械共振。

在电流采样、PLL和速度环未完成确认前，不建议直接到3500 rpm以上。

## 11. 当前建议结论

1. `Pulse=4000` 已经通过数据证明不适合当前PWM和采样结构。
2. `Pulse=5` 与50都可工作，当前代码保留50，但需要A/B/A重复确认。
3. U/W相电流仍有约10%～17%的幅值差，应优先确认硬件增益和采样时序。
4. 当前12～16 Hz摆动会进入速度环Iq，速度PI确实在参与放大该摆动。
5. 当前 `Kp=0.004`、`Ki=0.003` 仅作为现状快照，不作为新板推荐起点。
6. 无感速度必须增加独立滤波；编码器测速滤波对纯无感反馈不起作用。
7. 在增加PLL残差遥测并提高USB采样率前，不能可靠完成408 Hz角误差相干性判断。
