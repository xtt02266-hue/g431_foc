# BM3514H + MT6826S：历史日志分析与逐步排查实施方案

编写日期：2026-09-22。对象：BM3514H 小云台电机、原 AS5600 板更换 MT6826S、STM32G431 固件和 HapticKnobStudio 上位机。

本文件是当前证据下的诊断与实施方案，不表示以下诊断功能已经写入固件。本次工作只新增分析脚本、统计结果和本文档；未修改控制算法、未下载固件、未打包上位机。

## 1. 当前结论与排查优先级

1. **强拖稳定、闭环波动大是可重复现象。** 两份对照日志中，强拖稳态速度标准差约 3.7 rpm，闭环约 39～40 rpm。
2. **降低电流环带宽没有解决速度波动。** 最新闭环 Uq 波动减小，但机械速度波动基本不变。停止反复用带宽试错。
3. **速度 PI 输出到实际 Iq 目标之间存在明显差距。** 最新日志在速度峰值处，PI 要求约 −0.130 A，但最终 Iq 目标约 −0.00059 A。当前 5 A/s 的 Iq 限斜率是必须验证的候选因素。
4. **电流采样仍需要验证，但尚不能认定是根因。** 两份强拖日志反推的 U/W 基波幅值相差约 4%；这也可能包含真实相电流差异、角度误差及遥测不同步。
5. **编码器通信故障的优先级下降，但编码器角度精度和换相仍未完全排除。** 最新三份日志的编码器状态、CRC 错误、传输错误均为 0；这不等于角度绝对正确。
6. **早期“手动慢转角度跳变”和当前“主动闭环周期波动”不能直接合并为同一个故障。** 早期日志字段少、部分采样稀疏；后期强拖已能提供稳定角度和速度反馈。

推荐执行顺序：

> 冻结基线 → 增加同步诊断数据 → 检查零偏与 PI/最终 Iq 差值 → 一次只改一个因素 → 分离调制、换相、电流环、速度环 → 有证据后修复 → 多工况验收。

### 2.2 字段变迁必须正确处理

- 21 列日志：time_s + CH0～CH19，其中 CH19 是上位机滤波后的 Iq。
- 27 列日志：新增位置、电角度、未滤波速度估计等；CH25 是上位机滤波后的 Iq。
- 31 列日志：CH25 是编码器原始计数，CH26 是状态，CH27/28 是 CRC/传输错误，CH29 才是上位机滤波后的 Iq。
- 必须按完整列名解释，不得跨版本把 CH25 全部当作原始角度。
- CH24 的“raw speed”仍然是位置窗计算出来的速度，并非直接测得的瞬时物理速度。
- CH10=0 不代表一定停机：位置模式、自由模式、手动转动等也可能为零。

### 2.3 分段与统计规则

1. 历史恒速区间：按连续、相同目标速度分段；原段至少 1.5 秒，去掉前 1 秒，至少保留 50 行。
2. 强拖与闭环对照使用固定时间窗，见第 4 节。分段依据操作背景与目标/PI/Id 特征；CSV 没有显式强拖标志，因此模式标注属于有依据的推断。
3. 标准差使用总体标准差（ddof=0）。所有速度统计均来自 CH4，未额外平滑，也未按速度高低删除峰值。
4. 原始角度差分使用 32768 计数一圈的最短回绕差。老日志没有原始角度计数时，只能将 CH6 换算为等效计数，不能称为原始 SPI 数据。
5. 机械位置谐波使用 `v(θ)=c+Σ[a_h cos(hθ)+b_h sin(hθ)]`，联合最小二乘拟合 h=1～14；幅值 `sqrt(a_h²+b_h²)` 为峰值幅度，不是峰峰值。
6. 本文低速谐波数字均使用上述统一方法。与之前聊天中“512 分箱后 FFT”的数值会有差异，不能把方法差异当成电机变化。
7. 对高转速、稀疏采样和大缺口，不用高次谐波作定量结论。200 Hz 日志在 550 rpm 时，第 14 机械阶已超过 100 Hz；统计工具虽可计算空间拟合，不能据此确认真实高频动态。
8. 当前遥测不是严格同步的 ADC 快照，dq/角度反推和毫秒级因果顺序仅作线索。
9. CSV 不含固件哈希、运行时 PI 增益、电源实际电压、模式切换事件。163103/164345 分别代表改带宽前后的归因依赖用户操作描述；当前源码确为 250 Hz，但 CSV 自身不能证明历史固件参数。

### 2.4 数据质量

- 12 份日志数值字段均未发现 NaN/Inf，时间均严格递增。
- 233916/234738 平均间隔分别约 216.1/216.0 ms，仅约 4.6 Hz，无法分辨短时间角度更新。
- 234857 最大时间间隔为 14.9 秒，跨该间隔的差分不可当成均匀采样。
- 112650 记录间隔约 5 ms；其后大多约 5 ms，个别日志最大间隔达 18 ms。
- 停机时原始角度重复是正常情况，不能把全日志相邻重复计数称为丢帧。
- 缺少错误通道的旧日志应记作“未记录”，不能填成“0 错误”。

## 3. 历史数据说明了什么

### 3.1 早期阶段：存在严重异常，但不足以判定具体硬件原因

| 日志 | 全段 CH4 最小/最大 rpm | 可成立的结论 |
|---|---:|---|
| 233916 | −2812.44 / 923.77 | 与慢转描述不相符，反馈/计算异常需要排查；采样很稀疏 |
| 234738 | −16.31 / 1035.07 | 存在异常速度尖峰；缺传感器状态和原始帧证据 |
| 234857 | −5006.09 / 1.87 | 大负向尖峰，且有 14.9 秒日志间隔；不可用整段频谱判断 |
| 112650 | −5003.43 / 3362.24 | 在慢转背景下明显不合理；不能从 CSV 单独断定磁铁或安装问题 |

早期日志没有记录控制权、ACK、完整状态机和协议接收状态，不能仅凭 CSV 解释“接管/释放按钮灰色”。按钮问题应查上位机对 STATUS、owner、state、token 的处理以及串口协议，而不是据此更改电机 PID。

### 3.3 用户报告的角度不敏感区

历史报告提到原始计数 2700～3400、16800～17400 附近“不更新”。这些范围对应约 29.7°～37.4°、184.6°～191.2°机械角。

最新 154645 及两份强拖/闭环稳态窗内，没有相邻遥测原始角度完全相同的样本。此证据只表示这些区间未观察到持续约一帧或更久的停滞，不能排除小于 5 ms 的异常，也不能否认更早固件曾出现问题。

200 rpm 下每 5 ms 平均转过约 546 个计数；上述区间宽度分别只有 700、600 个计数，一次日志采样就可能跨过大半区间。后续检查应记录连续样本序号和角度差分，不能把“某个角度范围内样本少”直接当作 SPI 数据缺失。

Uq 标准差下降约一半，机械速度标准差仍约 40 rpm。可将“带宽过高是唯一根因”降级；不能宣称降低带宽毫无任何作用，也不能从 200 Hz 日志判断 20 kHz 电流环完全稳定。

### 4.3 机械位置的 7/14 阶波动

| 文件/模式 | 机械第 7 阶幅值 rpm | 第 14 阶幅值 rpm |
|---|---:|---:|
| 163103 强拖 | 1.41 | 0.80 |
| 163103 闭环 | 38.11 | 22.84 |
| 164345 强拖 | 1.50 | 0.80 |
| 164345 闭环 | 38.54 | 22.01 |

BM3514H 标称 7 极对，机械 7 阶/14 阶分别对应一倍/二倍电频。200 rpm 时约为 23.3/46.7 Hz。

这种对应关系支持“与换相、电流测量或电周期力矩有关”的排查方向，不足以单独判定偏置、增益、零点中的哪一个错误。闭环也可能放大本来较小的机械或角度周期扰动。

### 4.4 Iq 限斜率：最新日志中可直接观察的差距

164345 的 19.003 秒附近：

| 通道 | 值 |
|---|---:|
| CH4 机械速度 | 390.7997 rpm |
| CH11 速度 PI 输出 | −0.1296026 A |
| CH8 最终 Iq 目标 | −0.0005892 A |
| CH1 电流 PI 目标 | −0.0005892 A |
| CH2 实际 Iq | +0.0089358 A |

在最新闭环稳态窗，`CH11−CH8` 的绝对值超过 20 mA 的样本占约 13.0%；最大差距约 129 mA。该窗摩擦、齿槽补偿输出均为零，不能用这些前馈解释差距。

当前代码把速度 PI 输出经过 5 A/s 的限斜率后才交给电流环。对于幅值 0.05 A、23.3 Hz 的正弦修正，其最大变化率约为 7.3 A/s；对于 46.7 Hz 则约为 14.7 A/s。5 A/s 有可能造成补偿不足或滞后。

这说明 PI 输出不能及时落实是值得单独验证的环节，但不证明它是最初扰动的来源。遥测尚未同步，不能用单行数据推断准确延迟；应补充限斜率活动标志并作 A/B 测试。

### 4.5 相电流反推只作线索

按代码的逆 Park/Clarke 关系：

```text
Iα = Id*cos(θe) - Iq*sin(θe)
Iβ = Id*sin(θe) + Iq*cos(θe)
IU = Iα
IW = -0.5*Iα - sqrt(3)/2*Iβ
```

对强拖稳态窗拟合每相的直流分量与电角度基波：

| 文件 | U 基波幅值 A | W 基波幅值 A | W/U−1 | U 拟合直流 A | W 拟合直流 A |
|---|---:|---:|---:|---:|---:|
| 163103 | 0.38922 | 0.40510 | 约 4.08% | −0.00481 | +0.00052 |
| 164345 | 0.39492 | 0.40993 | 约 3.80% | −0.00690 | +0.00199 |

重复出现的幅值不对称需要检查，但不能直接将 W 增益除以 1.04。这里的电角度、dq 可能跨中断读取，且真实绕组和驱动也可能不对称。独立已知电流测量或同步原始 ADC 才能确认采样增益。

强拖中的 Id≈0.40 A 是使用当前编码器零点计算出来的投影，不是独立测量的“真实磁链轴电流”。不能据此证明零点一定正确，或宣称强拖必然用纯 Id 工作。

## 5. 当前代码中已核实的检查点

| 位置 | 已核实的事实 | 检查意义 |
|---|---|---|
| `user/src/motor_system.c` | 当前控制电流环带宽 250 Hz | 记录运行时实际值，防止改错宏/下载旧固件 |
| `user/src/motor_current_loop.c` | 另有默认 200 Hz 宏，但系统使用带宽参数接口 | 改默认宏未必影响系统实际整定 |
| `user/inc/motor_speed_loop.h` | 速度 Kp=0.0008、Ki=0.0005 | 单位是 rpm→A，不能套其他电机参数 |
| `user/inc/motor_config.h` | SPEED Iq 限斜率 5 A/s；目标速度默认斜率 0 | 两种斜率不同，需分别记录 |
| `user/src/motor_current_loop.c` | U 取负，W 保持正；各自偏置 | 必须与实际旧板的通道、分流方向对应 |
| 同上 | 原始 ADC 经 α=0.25 滤波后转 uint16_t，再存 sample.*_raw | 现有名字中的 raw 不是真正未滤波 ADC；截断还会带来小误差 |
| 同上 | ADC 回调先 SPI 读编码器，再读取 JDR/计算 FOC | 需测最坏延迟、回调频率和数据时序 |
| `user/src/hardware_init.c` | 两路各平均 500 次，但未检查 Start/Poll 返回状态 | 可能把失败/陈旧采样算入均值，需检查而非假定发生 |
| 同上 | TIM1_CH4 先运行，ADC 配外部触发；注释称软件触发 | 实际触发由寄存器与 HAL 行为决定，应修正注释和验证采样完成 |
| 同上 | 电流偏置在六路 PWM 启动前标定 | 需对比 PWM 开启前后零点 |
| `Core/Src/tim.c`、`Core/Src/adc.c` | 中心对齐、CCR4=5、CC4 注入触发、U/W 顺序转换 | 采样点是否正确须结合实际波形和计数方向 |
| `user/src/svpwm.c` | 闭环用共模注入 SVPWM；强拖直接三相正弦 CCR | 强拖/闭环的调制路径并不相同 |
| 同上 | Disable 设置三相 50%，不直接停六路 PWM | STOP 不是物理断电，转动时零矢量也可能产生电流/制动 |
| `user/src/pc_protocol.c` | 遥测分字段读共享状态、没有同步控制周期标识 | 需要同步快照后才能精确反推相位 |

工程内原理图显示 U/W 相线串联 16 mΩ 分流电阻、INA240A1，以及 ADC 前的 RC。该图是否与用户正在使用的旧 AS5600 板完全一致需要核对；尤其是通道、增益、分流方向和元件实装值。

INA240 的 PWM 抑制能改善共模瞬变恢复，但不是任意时刻采样都无误差的保证。[TI INA240 官方资料](https://www.ti.com/lit/ds/symlink/ina240.pdf)。电流采样的偏置、放大倍数与硬件映射也应按实际板定义核对：[ST 电机控制板说明](https://wiki.st.com/stm32mcu/wiki/STM32MotorControl%3AMotor_Control_Boards_Description)。

## 6. 逐步检查与实施流程

### 步骤 0：冻结基线与明确停止行为

**目的：** 保证 A/B 结果可比较，且新诊断不会误启动。

1. 保存当前固件源码差异、编译产物哈希、上位机源码版本和 Flash 电机参数备份。
2. 记录实际电源电压，不把代码中的 15 V 当作实测值；记录实际板版本/照片或原理图版本。
3. 记录 R、L、极对数、方向、零点和当前 PI。7 极对是产品规格；R=3.1 Ω、L=1.2 mH 的相/线定义未经确认，不能直接覆盖辨识值。
4. 保留电流环 250 Hz、速度 Kp/Ki 和安装位置。所有补偿的开关及实际输出都记录下来。
5. 确认 STOP、释放和失联会撤销诊断运行；新增测试必须有时长上限。
6. 将“零矢量停止”和“桥臂禁用”明确区分。校准前转子必须静止；不能把转动时 STOP 后的电流当成零偏。

**完成标志：** 每份日志能对应唯一固件和参数，且测试终止路径经过验证。

### 步骤 1：实现同步电流诊断遥测（第一版先观测）

**目的：** 原始数据、控制量和角度来自同一个已标记的周期。

建议新增以下字段，具体通道号以协议新 schema 定义为准，不复用旧字段含义：

| 字段组 | 字段 |
|---|---|
| 模式 | state、mode、force_drag_active、current_loop_enabled、run_requested、stop_reason |
| 采样 | adc_seq、sample_tick、IU_adc_raw、IW_adc_raw、IU_adc_filtered_f32、IW_adc_filtered_f32 |
| 标定 | bias_U、bias_W、calibration_valid、有效样本数/超时数/方差 |
| 电流 | IU、IW、Id/Iq、Id/Iq 目标、速度 PI 输出、限幅后/限斜率前 Iq、限斜率后 Iq、slew_active |
| 角度 | 编码器原始计数、FOC 电角度、强拖命令电角度、编码器样本年龄 |
| 输出 | Vd、Vq、CCR1/2/3/4、PWM 使能及限幅标志 |
| 时序 | ADC 调用计数、控制超期数、SPI 最长耗时、FOC 最长耗时 |

实施细节：

1. 在 ADC 回调读取 JDR 后保留原始值，再滤波。不要把滤波后的整数标为原始 ADC。
2. 快速中断完成计算后发布带序号的快照；主循环复制后检查序号，必要时重试。避免为打包串口长时间关中断。
3. 系统外环以 1 ms 更新，ADC 约 50 μs 更新，两者记录各自序号；明确同一 ADC 快照使用的是哪一版外环目标。
4. 增加遥测 schema 并同步上位机解析/CSV 字段；旧日志仍能读取。200 Hz 遥测按带宽预算分组或抽取，不在 ADC ISR 内发送串口。
5. 高频毛刺使用短记录缓存：例如 512 点、20 kHz 下约 25.6 ms，只保存必要原始量。按当前约 32 KB RAM 预算核算容量，停止捕获后再导出；不足一电周期时不能据此做 23 Hz 纹波频谱。
6. 上位机显示“开环强拖”而非仅显示旧 SENSORED_RUN，区分 200 rpm 磁场命令与实测机械速度。
7. 未同步前的 dq 反推结果保留为历史线索，不拿来写入校准参数。

**验证：** 串口序号连续、字节数符合 schema、没有越界；开启诊断不增加 ADC 超期；停机与原有控制结果可复现。

### 步骤 2：零偏与启动标定检查

**目的：** 分清静态零点误差、PWM 共模影响和真实电流。

1. 上电静止，记录两路原始 ADC 的均值、标准差、最小/最大值和当前偏置。
2. 在确认桥臂禁用时记录一组；在确认三相相同占空比、转子静止且电流衰减后记录另一组。
3. 运行前后及预热约 30 秒后重复，至少做三次独立上电。
4. 对比两路均值相对偏置的差，并对照供电/参考电压。
5. 检查 Start/Poll 返回值、JEOS/转换完成语义及两路 rank 是否来自同一序列，失败样本不得计入均值。

按代码名义参数，1 count≈2.52 mA。先以平均残差约 1～2 count 为工作目标；瞬时噪声应另报 RMS/P99，不能要求每个瞬时点都在 ±2 count 内。

| 现象 | 判断方向 | 实施动作 |
|---|---|---|
| 桥臂禁用就明显偏离 | 标定/参考/偏置存储 | 修复采样有效性、独立偏置计算 |
| PWM 开启后均值改变 | 共模、地噪声、采样窗口 | 先确认电流为零，再进入步骤 4 |
| 随预热明显漂移 | 参考电源、热漂、布局 | 实测参考/放大器输出，评估停机重校准 |
| 均值好但尖峰多 | 采样时刻、饱和或干扰 | 原始波形与 PWM 对照 |

若证实 PWM 开启前后偏置不同，第二版再实施“静止零矢量校准”：预装正确 CCR、确保闭环关闭，等待稳定，采集足量有效序列，检查方差和均值范围，通过后原子更新两路偏置。失败保持不可启动或明确故障，不静默写入无效值。

不得在运行中连续估计偏置；真实扭矩电流会被误扣除。转子还在转时，零矢量也不能作为零电流依据。

### 步骤 3：检查两路通道、极性和增益

**目的：** 将“采样错误”与“真实电流不对称”分开。

1. 断电核对实板：U/W 分流位置、INA240 型号后缀、16 mΩ 实装、ADC 到 PA0/PA2 的连接，确认没有沿用另一块板的定义。
2. 两路使用相同电流正方向约定。当前 U 取负、W 正号只能在电路对应时成立，不要盲目翻转符号尝试闭环。
3. 同步采集强拖下 IU/IW，观察正负半周、直流偏移、幅值、削顶和相位关系。
4. 在有独立电流参考时，以多档正负已知电流验证 `ADC = bias + gain*I`。只有一个工作点不足以分离偏置与增益。
5. 无独立电流测量时，可做限时低幅值固定电压矢量作为通道/极性一致性测试，但不得将其当作精密绝对增益标定。

固定矢量测试的理想符号关系（假定三相映射正确、星形平衡、转子摆动已结束）：

| 电压 αβ 矢量方向 | 理想 IU | 理想 IV | 理想 IW |
|---|---|---|---|
| +α | 正 | 负，约 IU 的 −1/2 | 负，约 IU 的 −1/2 |
| −α | 负 | 正 | 正 |
| +β | 约零 | 正 | 负 |
| −β | 约零 | 负 | 正 |

现有 `Motor_OpenLoop_Drive(theta)` 的电压矢量角为 `theta−π/2`，不可直接把输入 theta 当成 αβ 矢量角。测试前必须确认这一相位约定。

从低电压、短时开始，使用限流供电和自动超时；记录转子是否还在运动，移动期间的反电动势会破坏静态比例。若真实相线/ADC 极性不符，先修映射再重做相关换相标定。

**通过条件：** 极性可重复、没有削顶，静态偏置达标；多点增益误差在实装器件/测量误差预算内。1%～2% 可作目标，非对该板未经验证的硬性规格。

注意：IV 是 `−IU−IW` 重构值，三相和为零是恒等式，不能验证采样正确。

### 步骤 4：ADC、PWM、SPI 时序检查

**目的：** 判断错误是否随采样位置/控制延迟变化。

1. 用空闲 GPIO 或 DWT 周期计数测 ADC 回调次数、最坏耗时，核对实际 PWM 频率及每 PWM 周期触发次数。
2. 将编码器 SPI 耗时和 FOC 计算耗时分开记录，检查 JDR 是否被下一序列覆盖、是否有 overrun/超期。
3. 结合 TIM1 CNT 方向、CCR4、ADC 两个 rank 的采样/转换时长确定两路实际采样窗口。
4. 示波器同时观察驱动输入或合适的 PWM 参考信号、放大器输出和 GPIO 标记。回调入口是转换完成之后，不等于采样开始。
5. 在当前占空比附近选两到三个有明确稳定余量的采样点，逐一 A/B；记录均值、原始尖峰、dq 纹波和速度纹波。
6. 若改善随采样点稳定复现，再选择窗口并确认不同占空比下仍有效；不要仅凭改一次 CCR4 试转正常就结束。

`CCR4=5` 不自动代表贴近三相开关沿。按名义 170 MHz 计数时钟，5→100 只移动约 0.56 μs，是否足够需要实测。三相中点开关、中心对齐方向、ADC 序列和 PWM 预装载共同决定有效窗口。

板子如果确为相线分流，不能照搬低侧采样的可观测区规则。INA240 输出仍可能有共模恢复；ADC 前 RC 也影响建立时间。

**通过条件：** 实际控制 dt 与 PID dt 一致，无超期，采样覆盖稳定区，两路顺序采样影响在可接受范围。改时钟后应连同 PWM、ADC、SPI、速度 dt 和 PID dt 一起核对。

测量相线/分流两端时使用适当差分探头，普通接地示波器地夹不可接电机相线。运行中不要随意断点暂停 CPU，因为 PWM 可能继续输出。

### 步骤 5：先隔离调制差异，再分离换相与各个环

**目的：** 每个对照只新增一个主要依赖。

| 模式 | 角度来源 | 电流 PI | 速度 PI | 调制 |
|---|---|---|---|---|
| A：现有强拖 | 固定频率累计角 | 关闭 | 关闭 | 直接三相正弦 CCR |
| B：同频同电压强拖 | 同 A | 关闭 | 关闭 | 经现有 SVPWM_SetVoltage |
| C：编码器换相固定 Vq | 编码器角 | 关闭 | 关闭 | SVPWM |
| D：固定小 Iq | 编码器角 | 开启 | 关闭 | SVPWM |
| E：200 rpm 闭环 | 编码器角 | 开启 | 开启 | SVPWM |

执行方式：

1. 先对比 A/B：保持电角速度、物理电压矢量幅值和相位约定一致。当前 amplitude=100 对应相对中点占空比幅值 0.1，在实际 15 V 下相电压幅值约 1.5 V；不能把“100”当成伏特传给 SVPWM。
2. A 正常而 B 异常：查 PWM 通道映射、CCR 更新、SVPWM 与采样共模条件，不先调 PI。
3. B 正常再试 C：固定低幅值 Vq，记录角度、转速和电流。检查极对数、相序及零点；固定 Vq 不是恒速控制。
4. C 正常再试 D：固定小 Iq，先确认零偏和极性，记录是否重新出现周期力矩/角度纹波。
5. D 正常再试 E：重点进入步骤 6，检查测速延迟、速度 PI 和 Iq 限斜率。

新增 B/C/D 模式必须先具备限时、失联退出、手动停止和超速退出。固定 Vq/Iq 的空载速度会变化，不直接按原来的 200 rpm 恒速测试时间长转。若没有独立速度反馈，基于同一编码器的超速保护不能作为唯一防护。

“正常”需结合实际速度区间、波形与重复性；高吸合电流的强拖与几十毫安闭环不能被当成相同工作点。C/D 结论属于范围定位，不是严格数学排除所有未参与环节。

### 步骤 6：单独验证 SPEED Iq 限斜率

**入口条件：** 基础零偏/极性无明显错误，有同步的 PI 输出、最终 Iq 和活动标志。

1. 保持速度目标斜率为 0，并明确这是目标速度斜率；保持 Iq 幅值限制不变。
2. 先记录 5 A/s 基线，统计 slew_active 占比、`Iq_pre_slew−Iq_applied`、峰值附近滞后。
3. 仅提高 SPEED 模式 Iq 变化率，例如先 10 A/s，再视结果试 20 A/s；这些是诊断候选值，不是已验证最终值。其他模式不跟随修改。
4. 每档采集启动以外的 10 秒稳态，至少重复两次；记录电流是否出现新振荡和电压是否饱和。
5. 若速度峰值显著下降且 PI/最终目标差距缩小，可确认限斜率是重要放大因素。
6. 若差距缩小但 7/14 阶纹波仍在，继续查电流/换相/真实扰动来源，不能靠提高斜率掩盖问题。
7. 若新电流振荡、温升、失步或峰值增加，退回上一档；先检查电流闭环再继续。

不要第一步直接取消限斜率，也不要同时把电流上限提高。幅值限流与变化率限制职责不同。

### 步骤 7：电角度、零点与方向验证

1. 确认 Flash 和运行时极对数均为 7，方向为有效的 ±1，参数格式有效不代表参数物理正确。
2. 在多个位置做短时固定矢量对齐，检查转子是否停止，重复相同矢量是否回到可重复角度。
3. 比较命令电角度与 `7×机械角×方向` 的关系，处理 2π 回绕和输入角到电压矢量的 −π/2 偏移。
4. 正反方向缓慢扫角，比较相位误差随速度和机械位置的变化。随速度变化偏向延迟；随位置重复偏向角度非线性/机械或磁场因素；恒定偏差才适合讨论固定零点修正。
5. 保留旧参数备份，验证通过后再保存 Flash。不要每次测试都重新辨识，否则对比条件改变。

强拖 Id 大、Iq 小只说明当前计算坐标下如此；不能据此把零点判定为完全正确。电流采样误差也会影响这种判据。

### 步骤 8：最后调速度环与测速滤波

**入口条件：** D 模式电流与换相基本正常，E 模式仍异常，或步骤 6 指向外环滞后。

1. 验证速度计算实际周期、5/10/20 ms 自适应窗切换和编码器回绕；记录未滤波速度与控制实际用到的速度。
2. 保留当前滤波，先单独降低速度 Kp 做诊断。若波动下降，说明外环参与放大，但不自动说明传感器没有误差。
3. 固定 Kp，再逐步调整 Ki，观察稳态误差、低频摆动和积分饱和。转子惯量未知，不预先给出“最终正确 PID”。
4. 只有证据指向测量噪声才调整滤波；滤波更强会增加延迟，不能只以曲线看起来平滑为成功标准。
5. 最后才讨论摩擦/齿槽补偿，不用 LUT 去补偿尚未修复的电流采样或换相错误。

## 8. 每轮测试执行清单与结果记录模板

### 8.1 执行顺序

1. 确认固件版本和运行时参数，拍下/导出参数页。
2. 固定安装、电源、负载；电机静止后记录零点。
3. 强拖记录一次，确认基线仍约 200 rpm。
4. 运行选定测试模式，等待启动过程结束后采集 10 秒。
5. 停机，记录退出原因、温度/异常现象。
6. 只改一个变量，重复步骤 2～5。
7. 对比同一统计方法下的指标，而不是只截一张上位机曲线。

## 9. 验收标准与停止条件

以下是调试阶段目标，不是厂家性能保证：

- 200 rpm 无外加负载稳态标准差首先降到 10 rpm 以下，平均误差以 ±5 rpm 内为初步目标；仍需按应用要求收紧。
- 7/14 阶纹波明显下降，在相同采样方法下可重复；没有因滤波加重而只隐藏曲线。
- 正负速度都能工作，先 ±100/±200 rpm，再扩展到 ±400 rpm。历史的 2000 rpm 上限不是当前诊断阶段必须达到的验收点。
- 零偏稳定、无采样饱和、无控制超期；错误计数、模式退出和日志缺口有明确解释。
- START/STOP、释放、通信中断、诊断超时和重启行为正确。
- 至少两次重复测试，以及冷机/温机测试。Flash 参数保存后再上电的行为一致。

出现异常升速、持续电流异常、失步、明显温升、通信或反馈失效时结束当前测试，保留日志。不要依赖“软件 Iq 目标限幅”来保证开环实际相电流；开环路径绕过电流 PI，且现有 STOP 是零矢量而非断电。

## 10. 对历史推断的修正

| 之前的说法 | 本方案采用的更准确表述 |
|---|---|
| 强拖正常，所以 MOS/电机/编码器全部没问题 | 能稳定强拖，降低严重缺相/机械卡死的可能；轻微驱动非线性、角度误差和低电流工作点问题仍需检查 |
| 降带宽无用，所以电流环一定正常 | 带宽不是唯一根因；电流采样和时序仍未排除 |
| 有 7/14 阶，就能断定零偏/增益错误 | 阶次是定位线索，闭环放大和真实力矩扰动也可产生相关阶次 |
| Id 一次波对应确定的约 20 mA 零偏 | 未去掉启动段且遥测不同步时不能定量认定；以静止原始 ADC 和同步相电流验证 |
| 两路幅值差 4%，直接改增益 | 先独立测量和同步采样，分清真实电流与测量误差 |
| IV 重构后检验三相和 | 恒等式，没有独立验证力 |
| CCR4=5 太靠近边沿，改100即可 | 需要实测三相边沿/计数方向/ADC窗口；谷底也可能正是稳定区 |
| STOP 就是关闭 PWM，适合立即校准 | 当前代码仍输出相同占空比；转子未静止时可能有真实制动电流 |
| CRC 为0就证明角度正确 | 只说明记录到的帧校验正常，不验证磁场、非线性、旧数据或零点 |
