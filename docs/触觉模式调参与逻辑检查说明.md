# 触觉模式调参与逻辑检查说明

更新时间：2026-10-23。适用于本工程当前的 Spring（弹簧）、Detent（档位）、Limit（软限位）实现。

本文中的“默认值”是当前固件默认值；“建议起点”是便于逐步调试的建议，尚未经过本次实机验收。
电流单位为 A，角度计算使用 rad，界面限位范围使用 °。所有力矩数值都是模型估算，不是力矩传感器测量。

## 1. 先按这个顺序操作

1. 确认已下载本轮对应固件，连接上位机，等待设备处于 STOPPED。
2. 点击“接管控制”，等待成功。上位机会读取设备参数；必要时再点击“读取设备参数”。
3. 选择 Spring、Detent 或 Limit，点击“应用所选模式”，确认实际模式已经改变。
4. 写入本次总电流限幅。初次验证建议从 **0.15 A** 开始，确有需要且运行正常时再试 **0.20 A**。
5. 修改参数，点击“写入触觉参数”，等待成功，再读取一次核对。
6. 将轴放在期望的中心位置，点击 START。首次实际控制周期捕获该位置作为中心。
7. 等待至少约 0.5 s 的齿槽补偿渐入后，再比较稳定手感。先慢转、小角度测试。

**每次点击上位机 STOP 后，都要重新接管、重新应用模式，并重新写入本次需要的限流。**

原因是上位机 STOP 走的是“停止并释放控制权”路径：设备会恢复 LOCAL / TORQUE / POT，
主机限流恢复默认 0.9 A。下拉框仍显示某个触觉模式，不代表设备已经重新应用该模式。
START 本身不会替你发送模式和触觉参数。

六项触觉参数在 STOP 后仍保留在 RAM；MCU 复位或断电后恢复固件默认。
写入触觉参数会发送完整六项，包括当前模式隐藏的字段，因此应先读取同步，避免旧界面占位值覆盖其它参数。
当前固件只允许 STOPPED 时写触觉参数和总限流；即使上位机提示 Speed 可以运行中写限流，也以固件返回为准。

## 2. 本次逻辑检查结论

### 2.1 找到并修正的问题

| 问题 | 原来的影响 | 本次处理 |
|---|---|---|
| 连续机械角使用 float 逐拍累加 | 累计角较大时，小的编码器步进被舍入，触觉位置可能不再正常变化 | 用 64 位整数累计编码器计数；先减整数中心再换算相对角 |
| 档位控制依赖不断变大的浮点档心 | 长期多圈旋转时，档内误差精度随累计角变差 | 用有界整数档内相位计算切档和恢复力，整档消去后才转换成 rad |
| 测速使用有符号 32 位累计计数 | 长时间同向旋转可能触发有符号溢出，标准 C 不保证结果 | 改为无符号模累加，显式恢复滚动窗口内的有符号短距离 |

绝对“连续角”遥测字段仍是 float，累计很大时显示精度会下降；它不再作为这三个模式的控制计算基准。
相对中心角遥测也先在整数域相减，再换算为 float，避免大绝对角相减丢失小位移。

### 2.2 已核对的正常逻辑

- 三种模式使用机械方向计算恢复力，再乘已辨识的换相方向；齿槽表已经是电磁 Iq 方向，不重复转换。
- 启动首拍锁中心，STOP 后重启重新锁中心，重复 START 不会重新定位中心。
- 弹簧跨编码器单圈零点时不改变恢复方向；它是多圈扭簧，不是自动选择最近一圈的回零控制。
- 档位使用约 55% 档距的切档阈值，正反方向形成迟滞，整数相位不会在静止后因浮点误差再次换档。
- 软墙目标只朝允许范围内；返回时不再施加向外阻尼，但仍保留把轴推回范围内的恢复力。
- 三种模式的模型电流、摩擦补偿和齿槽补偿合计受主机限流与 20 A/s 斜率约束。
- 参数越界、NaN、Inf、档数 0 会被配置接口拒绝；合法档数范围内没有除零。
- 标定、辨识、音乐、开环强拖继续使用各自流程，STOP / 故障仍撤销输出。

这些结论来自源码、整数边界检查和 ARM 固件离线回放，不代表实际手感、温升或中断耗时已通过。

## 3. 上位机六项触觉参数

| 参数 | 固件默认 | 接口允许范围 | 单位 | 含义与调节效果 |
|---|---:|---:|---|---|
| Spring K | 0.12 | 0～5 | A/rad | 弹簧基础刚度。增大后同样偏转需要更大电流，回中更强；同时附加阻尼也增加 |
| Damping B | 0.002 | 0～1 | A/(rad/s) | 基础速度阻尼。增大后转得越快阻力越明显；过大可能发黏、放大测速延迟影响 |
| Detent K | 0.40 | 0～5 | A/rad | 档心基础刚度。增大后档内吸附和过档阻力更强；过大可能频繁限流、回摆 |
| Limit K | 0.80 | 0～5 | A/rad | 软墙基础刚度。增大后越界恢复力更强；达到限流后继续增加 K 不会增加最大力 |
| Limit ±范围 | 90 | 5～180 | ° | 中心两侧各自允许的半范围。±90°表示总范围约180°，不是每侧45° |
| 档位数 | 24 | 1～128 | 档/机械圈 | 一圈的档位数量。档距约为360°/档数；档数越多，同样 K 下单档峰值越小 |

允许范围用于输入校验，**不是整段范围都适合当前电机和机械结构**。不要直接从上限开始试。

### 3.1 B 不是最终全部阻尼

三个模式都会按自身刚度增加一项阻尼：

```text
有效阻尼 B_eff = B + 0.025 × 当前模式的 K
```

| 模式 | 当前默认有效阻尼，A/(rad/s) |
|---|---:|
| Spring | 0.002 + 0.025×0.12 = 0.005 |
| Detent | 0.002 + 0.025×0.40 = 0.012 |
| Limit | 0.002 + 0.025×0.80 = 0.022，仅在墙外向外运动时使用 |

所以提高 K 会同时增强恢复力与附加阻尼；将 B 设为 0 也不代表完全没有阻尼。
把 K 设为 0 也不一定没有电流：B、摩擦补偿和齿槽补偿仍可能产生输出。需要完全撤销输出时使用 STOP。

### 3.2 K 与实际力矩的关系

K 的单位是 A/rad，不是 N·m/rad。本工程按 `Kt = 0.23 N·m/A` 估算电磁力矩：

```text
估算电磁力矩 ≈ Iq × 0.23
```

这不是轴端净力矩反馈；实际轴端还受摩擦、齿槽、负载和模型误差影响。

## 4. 三个模式实际怎样工作

### 4.1 Spring：扭簧回中

中心附近 ±0.15° 是恢复力静区。静区外，偏转越大，刚度逐渐增强；大约90°偏转时达到最高渐硬倍率。
速度阻尼在回中时帮助抑制过冲。静区只去掉位置恢复项，不会去掉速度阻尼或两种补偿。

默认 K=0.12 时，零速度、未限流、不计补偿的近似电流为：

| 相对中心偏转 | 模型恢复电流绝对值 |
|---|---:|
| 15° | 0.032 A |
| 30° | 0.069 A |
| 60° | 0.181 A |
| 90° | 0.376 A |

例如总限流0.15 A时，转到60°附近已经会被裁剪；不能据此认定 K 没有生效。
这些是计算值，不是实测值，最终电流还要叠加补偿、限流和斜率限制。

### 4.2 Detent：档内吸附与越档切换

默认24档，一档约15°。以旧档心0°、下一档心15°为例：

- 正向越过约8.25°才从0°档切到15°档。
- 模型恢复目标立即转向新档心；最终电流仍受斜率约束，可能短暂保留旧方向。
- 反向回转时，要退到相对旧0°档心约6.75°以下才切回；等价于相对新15°档心反向偏转超过约8.25°。
- 8.25°与6.75°之间约1.5°的区间是迟滞，避免半档附近反复切换。
- 档心静区取“档距的2%”和0.15°中的较小值。

实际阈值按编码器整数计数量化，与上述理想角度的差异小于一个编码器计数。
当前默认参数下，静态切档前模型峰值约0.113 A；切档时目标会换向，但实际输出仍受20 A/s斜率约束。
因此快转的档位感可以与慢转不同；不能用高速甩动一次的感觉替代慢速档位检查。

先确定档数，再调 Detent K。把24档改成48档而 K 不变，档距减半，档位通常会更轻、更密。

### 4.3 Limit：有限电流实现的软墙

范围内不产生虚拟墙电流，摩擦和齿槽补偿仍可工作。越界后，恢复力随穿透角渐硬。
只有继续往外转时才增加接触阻尼；往回转时移除这项阻尼，恢复力仍向内。

默认 K=0.80、零速度、不计补偿、未限流时：

| 越界穿透角 | 模型恢复电流绝对值 |
|---|---:|
| 1° | 0.014 A |
| 5° | 0.087 A |
| 10° | 0.279 A |
| 20° | 1.396 A，已高于默认0.9 A总限流，会被裁剪 |

总限流0.15 A时，即使继续往外转，也只能输出该限流以内的总电流。
软墙能被人手克服；它不是机械硬止挡，也不保证轴永远不能越界。
回到边界内，模型墙目标立即为零，但实际电流可能因斜率历史短暂衰减，最长时间取决于此前电流幅值。

## 5. 推荐调参顺序

### 5.1 先固定公共条件

1. 记录当前六项参数和已测试的齿槽配置，保持供电和机械安装条件一致。
2. 总限流先使用0.15 A；摩擦补偿先关闭，避免未拟合准确的助推掩盖虚拟手感。
3. 齿槽保持已确认的0.90增益、0.080 A限幅，先不要同时改变它与触觉刚度。
4. 每次只改一个参数，写入并读回后，做同样的慢速正转、反转、释放测试。
5. 如果怀疑齿槽补偿影响，可停机后临时关闭做一次对照，再恢复已确认配置；不要为对照直接覆盖保存数据。

### 5.2 弹簧

建议初始 `Spring K=0.06`、`B=0.002`，从中心两侧各15°、30°开始，确认释放后恢复方向正确。

- 太软且没有明显限流：K按0.01左右的小步增加，再试0.09、0.12。
- 回中反复摆动：先减小K，再将B增加0.001左右，逐次比较。
- 回来很慢、发黏：适当降低B；注意K本身仍带附加阻尼。
- 增大K后仍差不多：先看是否已经达到总限流，不要继续堆K。

### 5.3 档位

先固定24档，建议从 `Detent K=0.20`、`B=0.002` 开始，慢慢跨过同一档的正反切换点。

- 档位不明显且没有限流：K每次提高约10%～20%，逐步接近当前默认0.40。
- 档位过密、不易辨别：先减少档数，例如24改12，再重新评估K；较少档数在同K下会更强。
- 档心回摆或嗡鸣：先减K；必要时小步增加B，不能只靠增大总限流处理。
- 慢转清晰、快转模糊：同时检查转速、斜率和电流跟踪，不要只改K。

### 5.4 软限位

建议先设半范围45°便于找到两侧边界，从 `Limit K=0.40`、`B=0.002` 开始。

- 先在墙外1°、3°、5°检查恢复方向，再试较大穿透。
- 墙太软且没有限流：K依次小步试0.60、0.80。
- 很快碰到电流上限：当前最大阻力已经由总限流决定；增加K只会让更浅的穿透提前限流。
- 往回转仍明显被向外顶：停止测试，核对实际运行模式、方向、补偿和电流跟踪；不要用负K补救。

调稳一种模式再切下一种。三个模式共享基础B，改B会影响其它模式，需要回头简要复核。

## 6. 总限流与补偿参数

### 6.1 主机总电流限幅

当前主机默认0.9 A，接口允许0.02～1.9 A。本文件建议的0.15～0.20 A只是初次验证起点。
三种触觉模式使用“虚拟模型＋摩擦补偿＋齿槽补偿”的总和限流，补偿会占用电流余量。
相同电流下，旋钮直径不同，手指感到的切向力也不同。

电位器力矩模式有独立±0.2 A总边界；普通POSITION位置模式沿用固定±0.9 A，
不能把本节的主机限流规则直接套用到所有其它模式。

### 6.2 齿槽补偿

| 参数 | 当前固件默认 | 含义 |
|---|---:|---|
| 启用 | 开 | 总开关；关闭后所有接入模式都不输出该补偿 |
| 整体增益 | 0.90 | 对标定表电流乘倍率，不是电流环P，也不是固定输出0.90 A |
| 最大补偿 | 0.080 A | 齿槽补偿自身正负限幅，最终仍受模式总限流 |
| 全量至 | 100 rpm | 按实际机械转速绝对值判断，低于此值不做速度淡出 |
| 关闭于 | 200 rpm | 100～200 rpm线性淡出，达到此值为零 |
| 相位偏移 | 0 count | 对机械角查表位置作偏移；一圈32768 count，不是电角度 |

增益允许0～10；最大补偿允许0～1.9 A，启用时须大于0；速度范围要求
`0 ≤ 全量至 < 关闭于 ≤ 645 rpm`，相位范围0～32767 count。
这些只是当前配置下的接口边界，不是建议调节范围。更改编码器映射后不能假定旧补偿表仍对齐。
有效保存的同来源Flash配置可覆盖内置默认；运行时按500 ms渐入。

### 6.3 摩擦补偿

模型为：

```text
I_friction = Ic × tanh(rpm / smooth_rpm) + Kv × rpm
```

| 参数 | 固件默认 | 接口范围 | 含义 |
|---|---:|---:|---|
| 启用 | 关 | 开/关 | 有效Flash记录可以恢复为开，实际应读回确认 |
| 库仑项 Ic | 0.020 A | 0～0.5 A | 运动方向上的近似固定摩擦补偿幅值 |
| 黏性项 Kv | 0 | 0～0.01 A/rpm | 随机械速度增大的摩擦补偿 |
| 平滑速度 | 20 rpm | 1～200 rpm | 零速附近由负补偿过渡到正补偿的平滑尺度 |
| 最大补偿 | 0.030 A | 0～1.9 A，启用时须大于0 | 摩擦补偿自身限幅，仍服从模式总限流 |

摩擦补偿沿运动方向助推，虚拟阻尼则反向阻碍运动；过补偿会减弱阻尼，可能出现自转或振荡。
平滑速度减小会让零速附近补偿更陡，不代表越小越好。先调稳三个虚拟模型，再单独校准摩擦。
默认摩擦系数只是初值，不代表已拟合当前实机。库仑/黏性参数的采集另见本目录现有摩擦操作文档。

## 7. 固件内部固定项：上位机六项参数调不到这些

| 固定项 | 当前值 | 含义 |
|---|---:|---|
| 中心恢复力静区 | 0.15° | 弹簧和档心附近减少小角噪声响应 |
| 档心静区比例 | 档距2%，且不大于0.15° | 档数变化时自适应缩小静区 |
| 换档门限 | 约0.55档距 | 与反向门限共同形成约0.10档距迟滞 |
| 附加阻尼时间尺度 | 0.025 s | 产生K×0.025的附加阻尼 |
| 弹簧渐硬角度 | 90° | 渐硬倍率从1逐步升到2 |
| 软墙渐硬角度 | 10° | 按穿透角增强，渐硬倍率最大5 |
| 软墙阻尼接触区 | 墙外0.5° | 从零连续建立向外运动阻尼 |
| 三模式总电流斜率 | 20 A/s | 每1 ms最多变化20 mA，不是电流最大值 |
| FREE / DAMPING斜率 | 1 A/s | 这两个模式保留原响应 |

上位机力矩命令中的“Iq斜率”不用于这三个模式，不能靠那个输入框改变20 A/s。
目前先调上位机六项参数、限流和补偿；没有明确数据支持时不建议同时修改上述固定项。

按曲线名称选择，避免混淆UI编号与CSV原始索引。当前上位机对应关系如下：

| CH12 机械连续角 | 看连续运动趋势；大绝对值时为float近似显示 | 7 |

## 9. 常见现象与处理

| 现象 | 优先检查 |
|---|---|
| 界面选了弹簧，实际却像恒定力矩 | 是否重新接管并应用模式，核对设备实际mode |
| 修改后没有变化 | 是否点击写入、是否收到成功、是否读回；是否已经饱和 |
| 上位机STOP后重新启动，力度比之前大 | 重新接管后的限流是否恢复0.9 A，是否忘记写回测试限流 |
| K=0仍有电流 | 基础B、摩擦和齿槽；真正撤销输出使用STOP |
| B=0仍有阻尼感 | 有K×0.025附加阻尼，还可能有实机摩擦 |
| 档数增加后档位变轻 | 档距减小，同K时峰值降低；重新调K而非直接扩大最大电流 |
| 软墙可以被手推过 | 有限电流软墙的正常限制；检查限流，不能当机械硬止挡使用 |
| 增大K只增加嗡鸣 | 限流、电流跟踪、测速延迟、阻尼或补偿误差；先退回上一组正常值 |
| 释放后持续自转或振荡 | STOP，先关闭摩擦做对照，降低K，核对换相方向和齿槽对齐 |
| 两侧恢复方向都不对 | STOP，检查辨识方向与编码器映射；不使用负K掩盖符号错误 |

每次记录：模式、六项参数、实际总限流、两种补偿配置、测试角度/转速、正反差异、目标与实测Iq。
每次只改变一个因素，保留上一组正常值，才能区分模型、限流、补偿和电流环的影响。
