# 位置模式摩擦前馈（固件1.12.0）

位置环输出目标机械速度rpm，同时作为速度环目标及摩擦模型输入。摩擦模型输出Iq前馈，按UVW方向转换后叠加到速度PI电流：

`Iq = speed_PI + uvw_dir * [Ic*tanh(position_target_rpm/smooth) + Kv*position_target_rpm]`

使用现有摩擦参数及启用状态，勾选“启用动态摩擦补偿”并在停机时写入/保存参数后生效。目标速度为零时模型输出为零；按目标速度可在转子尚未运动时提供起步前馈。位置/速度PI增益、Kd、测速处理不改变。

前馈电流按位置模式原有总电流边界夹紧，并从速度PI上下限扣除，让PI抗饱和考虑前馈占用的余量。PI与前馈相加后再次夹紧。位置模式暂不加入齿槽前馈。普通位置模式保持原有额定电流边界，逐点标定使用会话0.20A上限。

1.12.1逐点齿槽标定在移动阶段用原先保存且启用的摩擦参数辅助定位，到位后显式排除前馈，重新等待稳定再采集。运行配置仍暂时禁用，采样记录中的补偿电流保持零。结束、中止或故障后恢复配置，普通位置模式再次按启用状态使用摩擦参数。

上位机CH20摩擦补偿Iq曲线也可观察位置模式前馈；位置环目标速度另有现有通道。补偿可能改变到位过程和抖动情况，需实机验证现有smooth及增益是否适合。

HELLO版本1.12.0，新增能力bit14（0x4000），总能力0x7FFF。原有摩擦命令、普通遥测schema7、framing v2、自动采集记录版本均不变。新上位机显示位置补偿支持状态；旧固件仍可使用原有Free/Speed补偿，新固件可被旧上位机按原摩擦命令控制。

测试覆盖目标速度而非实测速度驱动、正负UVW方向、零目标、补偿禁用、前馈电流余量和逐点排除补偿。编译和模拟测试不代表实机到位性能已经通过。
