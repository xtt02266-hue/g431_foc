# 自动摩擦采集与断电保存（固件 1.9.0）

## 操作

1. 烧录固件 1.9.0，关闭并重新启动修改后的上位机，再连接串口。
2. 空载，点击“接管控制”，确认 STOPPED。无需先启动电机。
3. 展开“FREE / SPEED 摩擦补偿”，点击“自动摩擦采集：60 / 80 / 100 rpm 正反转”。
4. 流程自动加速、等待稳定、采集、减速至零、换向，每个方向采集 8 个合格圈。结束停机，恢复原来的模式、输入源、限流及补偿配置。
5. 合格后自动填入候选 Ic/Kv/最大电流，保留原来的平滑转速；点击“预览采样与拟合”，确认后手动点击“写入并保存摩擦参数（断电保留）”。无需再点拟合；如点拟合，会加载这次自动分析结果。不会自动写入或保存 Flash。
6. 中途可点击“中止自动采集并停机”或 STOP。失败记录仍保存，可在同步标定区查看逐圈质量报告。

无旧固件兼容能力时新按钮禁用并提示升级。普通控制和原有手动摩擦采样仍可使用。自动原始记录保存在上位机 `calibration_runs` 会话目录中的 `samples.csv`、`metadata.json`、`analysis.json`，不要用手动摩擦 CSV 的导出按钮代替。

## 方法与质量检查

- 采集期间临时关闭摩擦和齿槽补偿，使用现有 PID，不修改 PID 增益。采集电流上限取原限流与 0.20 A 的较小值。
- 按 1 kHz 同步记录机械角度、速度、最终给定电流和实测电流。拟合整圈平均所需电流，正反转按固件 UVW 方向归一化后配对。
- 稳定等待不少于 5 秒、5 圈，另需连续两个 1 秒窗口合格；窗口平均速度误差 ≤5%、速度误差 RMS ≤15%，且无停顿或硬异常。
- 整圈平均误差 ≤5%、RMS ≤15%、峰值偏差 ≤40%；上位机要求单圈角度覆盖 ≥95%，每档每方向至少 6 个完整合格圈。三档均需通过。
- 限幅、编码器异常、控制周期遗漏、丢包、重复包、补偿未关闭、明显降速或反向均拒绝；Iq 斜率限制单独记录，由整圈平均电流跟踪检查判断是否污染。
- 逐圈电流标准差 ≤max(2 mA, 平均值的15%)；正反转归一化电流差/两方向电流之和 ≤30%。平均实测与给定电流之差 ≤max(3 mA, 平均给定的20%)。
- 非负拟合 `Ic*tanh(rpm/smooth)+Kv*rpm`，拟合 RMS ≤max(3 mA, 平均电流的10%)；三档电流差不足三倍统计噪声时先置 Kv=0 并提示。
- 60/80/100 rpm 不能可靠测出近零速静摩擦与平滑区特性，因此保留原有 smooth。外部负载会混入测得的电流，标定应空载。

## 兼容性

HELLO 版本升级为 1.9.0，特性 bit10（0x400）表示自动摩擦采集，bit11（0x800）表示摩擦参数 Flash 保存，总能力 0xFFF。协议 framing v2、普通遥测 schema 7、同步记录 schema 1、64 字节记录、32 字节状态及已有命令保持不变。

`CAL_START (0x32)` 新增 mode=4；0～3 的齿槽诊断/采集/对照行为保持不变。上位机必须收到 bit10 才发送 mode=4。旧固件不支持新模式，不用旧命令模拟自动运行。

mode=4 状态 reason=7 表示不足三档合格速度；其它模式 reason=7 仍表示不足两档。正常结束、STOP、中止、故障和心跳超时均停机并恢复采集前配置；新拟合结果只在上位机预览。

软件已覆盖模拟状态机、数据分析、丢包/停顿/电流异常、版本能力门控及候选参数不自动写入。编译与模拟测试不等于实机完成；需烧录后验证本机采集结果。

## 摩擦参数 Flash 保存

新增命令 `0x35 SAVE_FRICTION_TO_FLASH`，body 与旧 `SET_FRICTION_PARAMS` 相同：17字节 `<Bffff>`，依次为 enabled、Ic(A)、Kv(A/rpm)、smooth(rpm)、max(A)。仅 HOST + STOPPED、无自动采集/待排空记录/电机参数任务时接受。成功先保存，再应用当前运行参数，回复相同17字节；Flash失败返回 NOT_READY，当前RAM参数保持原值。沿用命令去重及重试机制。

旧0x25仍只修改RAM，旧0x26仍返回17字节当前参数。旧上位机可继续控制新固件；新上位机在1.8.0及更早固件上禁用保存按钮，不发送0x35。

独立Flash页地址 `0x0801E800`（2KiB），程序区缩减为122KiB。齿槽页 `0x0801F000`、电机参数页 `0x0801F800` 地址保持不变，保存摩擦参数不擦除这两页。32字节摩擦记录含magic、版本、大小、参数和CRC32，开机检查格式、CRC和参数范围，通过才加载；无效时采用默认禁用摩擦补偿的配置。

首次标定后保存一次即可。以后重启直接使用，若要查看数值点“读取摩擦参数”；只有改变机械结构、负载或重新标定时需要重拟合。原始采样仍在电脑保留作诊断备份。
