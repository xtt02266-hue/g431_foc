# MT6826S编码器自校准

固件1.13.0、Haptic Knob Studio 0.10.0新增一键内部自校准，入口为“高级设置 → 故障与设备维护 → 编码器自校准 · 250 rpm”。本模式会自动旋转电机，须空载、不接触转轴。普通强拖诊断按钮保留。

连接串口，在STOPPED状态接管控制，然后点击校准。流程为固定磁场对齐、渐升至250 rpm、等待反馈速度在225～275 rpm内连续稳定1秒、设置芯片200～400 rpm自校准档并读回核对、触发芯片自校准、查询结果。运行中通过芯片状态0x113[7:6]确认，必须先观察到“运行中”，转动超过18圈后才接受“成功”；启动或状态超时、CRC计数变化、传感器警告、数据过期、转速越界及控制权丢失均中止。

完成会自动停机。显示成功只代表芯片报告完成，并不代表已经独立验证角度精度。按手册要求断开电机及编码器供电再重启，不能只按MCU复位。触发后中止或结果不确定时也锁定运行，要求完整断电重启。STOP保留无令牌、可重复的即时停机语义；清理芯片寄存器在主循环完成。

校准前将旧齿槽补偿设为关闭并保存，保留512点表值、CRC及源文件，避免断电重启后旧表再次自动生效。确认新角度后重新验证换相零位、重新标定齿槽。摩擦参数不改。校准状态及结果保存在上位机encoder_calibration_runs目录。

## 协议与兼容

- 帧版本2、普通遥测schema7及原有命令和状态长度不变。
- HELLO版本1.13.0，新增能力bit24（0x01000000）；旧版本不启用新按钮，普通功能保持可用。
- 0x39 ENCODER_CAL_START：空body、需要HOST令牌及STOPPED；ACK body为下述24字节状态。重复相同seq请求使用现有ACK缓存，不再次触发。
- 0x3A ENCODER_CAL_STATUS：空body，无需令牌，可在停机、失去控制权、等待重启时查询。长度错误拒绝。
- 状态body `<6BHIIff>`：schema(1)、phase、reason、flags、chip_status、frequency(4)、reserved(0)、elapsed_ms、calibrated_counts、measured_rpm、target_rpm(250)。读者检查最少24字节并允许尾部扩展。
- phase：0未开始、1升速、2稳定、3配置、4运行、5成功、6失败、7中止。flags bit0流程/清理活动、bit1需完整断电、bit2旧表停用、bit3观察到芯片运行。
- reason：0无、1停机请求、2控制丢失、3传感器、4速度、5SPI、6读回不一致、7芯片失败、8超时、9本次运行/圈数未确认。

SPI单寄存器读写使用0011/0110命令、12位地址和8位数据。配置0x00E只替换bits6:4为4，保留GPIO驱动和厂商保留位；核对读回后写0x155=0x5E。未发送全寄存器映射EEPROM编程命令。寄存器传输与20kHz角度DMA互斥，忙时让出，单次超时上限1ms；仅在主循环执行，不阻塞电机中断。芯片报告完成后暂停角度访问并禁止运动，等待断电重启。

依据：MagnTek MT6826S Datasheet Rev1.1，第8.6.3～8.6.6、10.2、11章：
https://www.magntek.com.cn/upload/pdf/202407/MT6826S_Datasheet_Rev.1.1.pdf

实际转子匀速程度与芯片校准后的改善仍需实机确认。本次软件构建和模拟测试不执行实机校准、不写实际芯片、不自动烧录。

## 软件验证

上位机180项单元测试通过；本地C模拟覆盖寄存器与DMA互斥、配置保留位、实际运行和超过18圈的成功确认、旧成功状态拒绝、CRC异常、超时、中止及触发时发生STOP。CRC回归验证保留上一有效角度及2ms过期保护。Debug固件构建通过，RAM使用28032/32768字节（85.55%），Flash使用104684/124928字节（83.80%）。
